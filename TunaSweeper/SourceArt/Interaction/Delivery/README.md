# Delivery placeholder art

Source: Delivery.blend. Exported meshes: SM_DeliveryBox.fbx (60 × 44 × 38 cm, bottom-center origin), SM_DeliveryDropoff.fbx (105 × 92.5 × 124 cm, floor origin).

T_Delivery_Atlas.png is an original procedural 1024² opaque cardboard/tape/label/pallet atlas. Both meshes use one material slot, nondegenerate UVs and beveled edges. Preview props/camera/lights in the blend file are not part of the exported FBX files.

UE assets: /Game/Interaction/Parcels/Meshes. Parcel and destination BP VisualMesh components can be replaced independently of gameplay logic. On parcels, keep Use Component Mesh Presentation enabled to preserve the BP mesh, material and transform through container data refresh.

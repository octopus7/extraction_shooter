# LunaMk2 운동복

사용자가 확인한 [운동복 시안](../OutfitConcepts/LunaMk2_Tracksuit_Concept.png)을 바탕으로 남색 트랙 재킷, 아이보리 어깨 배색과 소매·바지 두 줄 옆선, 발목 시보리, 짧은 양말과 운동화를 제작했다. 기존 모델에 맞는 별도 교체용 의상 원본이다.

## 결과물

- `LunaMk2_Sportswear.blend`: Blender 5.2 편집 원본. 의상·지퍼·주머니 입구·운동화·끈을 60개 파트로 편집할 수 있다.
- `Models/SKM_LunaMk2_Sportswear.fbx`: 의상만 합친 메시 1개, 30,746정점, 61,320삼각형, 재질 6개, 본 130개. 몸체·머리와 애니메이션은 포함하지 않는다.
- `Previews/`: 앞·뒤·옆·사선·상세 및 타이틀 A/B/C 착용 포즈.
- `materials.json`: 단색 PBR 재질의 선형 색상·거칠기·금속성 값. 새 의상에는 별도 이미지 텍스처가 필요 없다.
- `blender_validation.json`, `fbx_validation.json`: Blender 구조·변형과 FBX 재읽기 검사 결과.

## 보존과 편집 구조

| 컬렉션 | 내용 |
| --- | --- |
| `00_Original_Maid_Preserved` | 원래 캐릭터·메이드복·타이틀 스커트 보존 사본. 기본 숨김. |
| `01_Character_Preview` | 운동복 착용용 몸체 사본과 `SK_LunaMk2_Sportswear` 리그. |
| `02_Sportswear_Export` | 운동복·양말·운동화의 편집 파트. |
| `03_Preview_Studio` | 카메라·조명·바닥. |

기존 정비사 작업복 원본의 캐릭터와 하체 웨이트, 교복 원본의 소매 구조·웨이트를 바탕으로 새 의상 사본을 제작했다. 원래 `Blender/SKM_LunaMk2.blend`, 타이틀 모션, 교복·정비사 작업복, UE 캐릭터 파일은 수정하지 않았다. 얼굴·머리·머리 장식은 기존 모델을 유지한다.

`SKM_LunaMk2_SportswearBase`의 `Sportswear_BodyCoverage_Reversible` Mask를 끄면 가려진 원래 몸체가 복원된다. `Sportswear_VisibleBody` 그룹은 손과 목 위쪽을 표시한다. 의상 아래 몸체와 기존 신발·메이드 장식은 가려져 있다. 원래 의상을 보려면 01·02 컬렉션을 숨기고 00의 뷰포트·렌더 숨김을 해제한다.

## 리깅과 적용 조건

- 130개 본의 이름·계층·레퍼런스 행렬과 얼굴 표정 6개를 유지한다.
- 바지는 원래 thigh/calf twist 웨이트를 유지하고, 재킷과 장식은 몸통·팔 웨이트를 보간했다. 운동화는 foot/ball/calf를 최대 3개까지 혼합한다. 모든 의상 정점은 최대 4개 본의 정규화된 웨이트를 가진다.
- FBX는 두께를 적용한 의상 파트를 합쳐 `-Y Forward / Z Up`, 단위 변환 적용, leaf bone 추가 없음, 애니메이션 없음으로 내보냈다. Blender의 미터 단위를 UE 센티미터 변환에 맞춘다.
- 향후 UE 적용 시 몸체 가림 처리와 기존 스켈레톤·손목 후처리 설정을 함께 유지해야 한다. UE 임포트, 게임 장착, 의상 교체 시스템과 천 물리는 이번 범위에 포함하지 않는다.

## 검증 범위

원래 본의 레퍼런스 행렬, 얼굴 표정 좌표, 몸체 원본 지오메트리, 의상 UV·웨이트·연결·퇴화 면을 검사했다. 기존 타이틀 A/B/C를 각각 13프레임 평가하고 렌더를 검토했다. FBX를 빈 장면에 다시 가져와 본 계층, 좌표·범위, 삼각형 수, 재질, 웨이트를 비교했다. 모든 전투 모션의 옷 관통이나 UE 임포트까지 확인한 것은 아니다.

왼쪽 소매는 타이틀 B의 팔꿈치 안쪽에서 28.01mm 길이의 메시 모서리가 5.35mm로 압축되는 경고 1건이 있다. 깊게 접히는 팔꿈치 위치이며 포즈 렌더에서 찢어짐이나 줄무늬 단절은 보이지 않았다. 향후 다른 전투 모션을 적용할 때 해당 접힘을 함께 점검해야 한다. 발목 양말의 시보리 관통과 어깨 배색천의 미세한 표면 겹침은 렌더 검토 후 수정했다.

일회성 생성·내보내기 스크립트는 검증 후 제거했다. 이후 편집은 저장된 Blender 원본에서 진행한다.

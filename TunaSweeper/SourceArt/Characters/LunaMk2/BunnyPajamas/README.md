# LunaMk2 토끼 후드 잠옷

[사용자가 제공한 이미지](References/BunnyPajamas_UserReference.png)를 바탕으로 분홍색 토끼 귀 후드, 방울 달린 끈, 앞주머니, 넉넉한 긴 바지와 퀼팅 슬리퍼를 제작했다. 기존 LunaMk2 체형과 리그에 맞춘 별도 교체용 의상이다.

## 결과물

- `LunaMk2_BunnyPajamas.blend`: Blender 5.2 편집 원본, 의상·후드·귀·방울·슬리퍼를 구분한 47개 메시 파트.
- `Models/SKM_LunaMk2_BunnyPajamas.fbx`: 의상만 합친 메시 1개. 50,282정점, 100,460삼각형, 재질 4개, 본 130개. 몸체·머리와 애니메이션은 포함하지 않는다.
- `Previews/`: 앞·뒤·옆·사선·상세 및 기존 타이틀 A/B/C 착용 포즈 렌더.
- `materials.json`: 새 의상의 단색 PBR 재질 값. 별도의 의상 이미지 텍스처는 사용하지 않는다.
- `blender_validation.json`, `fbx_validation.json`: 구조·변형·FBX 재읽기 검사 결과.

## 보존과 편집 구조

| 컬렉션 | 내용 |
| --- | --- |
| `00_Original_Maid_Preserved` | 원래 캐릭터·메이드복·타이틀 스커트 보존 사본. 기본 숨김. |
| `01_Character_Preview` | 잠옷 착용용 몸체 사본과 `SK_LunaMk2_BunnyPajamas` 리그. |
| `02_BunnyPajamas_Export` | 새 잠옷·후드·귀·방울·양말·슬리퍼 편집 파트. |
| `03_Preview_Studio` | 카메라·조명·바닥. |

검증된 운동복 원본을 바탕으로 의상 사본을 제작했다. 원래 모델, 타이틀 모션, 교복·정비사 작업복·운동복, UE 캐릭터 파일은 수정하지 않았다. 원래 본 계층·레퍼런스 행렬, 머리·얼굴 좌표와 표정 6개를 유지한다.

`SKM_LunaMk2_BunnyPajamasBase`의 `BunnyPajamas_BodyCoverage_Reversible` Mask를 끄면 가려진 원래 몸체가 복원된다. 후드는 머리 장식을 감싸고 얼굴과 앞머리는 드러낸다. 머리 메시를 잘라내거나 새 머리 마스크를 만들지 않았다.

긴 양갈래 머리는 후드를 뚫고 나오지 않도록 **착용용 사본의 `SKM_Luna.SideTail_BunnyPajamasBase`만 뷰포트·렌더에서 숨겼다.** 해당 객체의 눈 아이콘과 렌더 표시를 다시 켜면 복원된다. 보존 컬렉션의 원래 머리는 변경하지 않았다. 원래 의상을 보려면 01·02 컬렉션을 숨기고 00의 뷰포트·렌더 숨김을 해제한다.

## 리깅과 후속 적용

- 본을 추가하지 않고 기존 130개 본을 사용한다. 후드 위쪽과 토끼 귀는 head, 아래쪽은 neck_01을 함께 따른다. 목 연결부는 몸통에서 목·머리로 웨이트를 전환한다.
- 바지·소매는 원래 twist 본 웨이트를 유지한다. 슬리퍼는 foot/ball/calf를 최대 3개까지 혼합한다. 모든 의상 정점은 최대 4개 본의 정규화된 웨이트를 가진다.
- FBX는 두께를 적용한 의상 파트를 합쳐 `-Y Forward / Z Up`, 단위 변환 적용, leaf bone 추가 없음, 애니메이션 없음으로 내보냈다.
- 향후 UE 적용 시 몸체 가림과 양갈래 머리 표시 상태를 의상에 맞게 반영해야 한다. 기존 스켈레톤과 손목 후처리 설정도 유지해야 한다.
- UE 임포트, 게임 장착, 의상 교체 시스템, 천·토끼 귀·방울의 물리는 이번 작업에 포함하지 않는다. 귀와 방울은 현재 형태를 유지하며 본을 따라 움직인다. LOD도 별도로 제작하지 않았다.

## 검증 범위

원래 본과 머리·얼굴·몸체의 보존, 의상 UV·웨이트·좌표·연결·퇴화 면을 검사했다. 타이틀 A/B/C를 각각 13프레임 평가하고 렌더를 검토하며, FBX를 빈 장면에 다시 가져와 본 계층·좌표·삼각형 수·재질·웨이트를 비교했다. 모든 전투 모션의 옷 관통이나 실제 UE 임포트까지 확인한 것은 아니다.

깊게 접히는 소매 안쪽에서 압축 경고 4건이 있다(왼팔 A/B/C, 오른팔 B). 가장 작은 모서리 길이 비율은 약 0.149이며 29.14mm가 4.35mm로 접힌다. 렌더에서 구멍이나 찢어짐은 보이지 않았다. 향후 다른 전투 모션을 적용할 때 해당 접힘을 함께 점검해야 한다.

정수리 봉제선의 기준축과 진행 방향이 평행해 생긴 퇴화 삼각형은 단면 기준축을 수정해 제거했다. 후드·목 연결부·끈 부착부와 슬리퍼의 퀼팅 선도 별도 시각 검토했다.

후속 편집은 저장된 Blender 원본에서 진행한다. 일회성 생성·내보내기·검사 스크립트와 중간 모델 파일은 제거했다. 정리 후 동일한 검사를 메모리에서 다시 실행해 Blender 오류 0건·접힘 경고 4건, FBX 오류 0건을 확인했다.

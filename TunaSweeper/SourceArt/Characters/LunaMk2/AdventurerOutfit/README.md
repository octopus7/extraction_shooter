# LunaMk2 멜빵 탐험가 의상

[사용자가 제공한 이미지](References/AdventurerOutfit_UserReference.png)를 바탕으로 아이보리 롤업 셔츠, 붉은 갈색 리본, 갈색 가죽 멜빵과 허리벨트, 카키 롤업 반바지, 손목 밴드, 주름 양말과 레이스업 워커를 제작했다. 기존 LunaMk2 체형과 리그에 맞춘 별도 교체용 의상이다.

## 결과물

- `LunaMk2_AdventurerOutfit.blend`: Blender 5.2 편집 원본. 옷·끈·버클·봉제선·아일렛·부츠 밑창을 167개 메시로 구분한다.
- `Models/SKM_LunaMk2_AdventurerOutfit.fbx`: 의상만 합친 메시 1개. 42,270정점·84,092삼각형, 기존 130개 본, 재질 6개를 포함한다. 몸체·머리와 애니메이션은 포함하지 않는다.
- `Previews/`: 앞·뒤·옆·사선·상세, 타이틀 A/B/C 착용 포즈와 B 후방 확대 렌더 9개.
- `materials.json`: 아이보리 천, 카키 천, 리본, 가죽 2종, 황동의 단색 PBR 재질 값. 의상 이미지 텍스처는 따로 사용하지 않는다.
- `blender_validation.json`, `fbx_validation.json`: 구조·변형·FBX 재읽기 검사 결과.

검증된 운동복 원본의 캐릭터 사본·몸통·팔·하체 웨이트를 바탕으로 제작했다. 원래 모델, 타이틀 모션, 교복·정비사 작업복·운동복·토끼 잠옷 및 UE 캐릭터 파일은 변경하지 않았다. 원래 130개 본 계층·레퍼런스 행렬과 머리·얼굴·몸체 좌표, 얼굴 표정 6개를 유지한다. 머리 장식과 양갈래 머리도 그대로 표시한다.

`SKM_LunaMk2_AdventurerOutfitBase`의 `AdventurerOutfit_BodyCoverage_Reversible` Mask를 끄면 가려진 원래 몸체가 복원된다. 노출된 목·팔·손·다리는 보존하고 새 의상 아래의 기존 몸체·신발·목장식을 가린다. 몸체 하단은 양말 안쪽까지 겹치도록 남겨 종아리와 양말 사이가 끊기지 않게 했다. 원래 의상을 보려면 01·02 컬렉션을 숨기고 00의 뷰포트·렌더 숨김을 해제한다.

## 리깅과 후속 적용

- 본을 추가하지 않고 기존 리그를 사용한다. 의상 정점은 최대 4개 본에 정규화된 웨이트를 가진다.
- 소매·반바지의 롤업 끝단은 원래 경계 링의 웨이트를 높이 방향으로 유지한다. 부츠는 foot/ball/calf와 기존 twist 본을 사용한다.
- 멜빵은 실제 셔츠 표면에, 허리벨트는 셔츠·반바지 외곽에 맞췄다. 금속 버클과 부츠 끈은 별도 편집 파트다.
- 손목 밴드와 버클은 좌우 전완 twist 본의 일정한 혼합을 사용한다. 멜빵은 높이에 따라 몸통 본의 웨이트를 연속 보간하며, 각 버클의 프레임과 핀은 같은 중심 웨이트를 공유한다. 손가락·상완 영향이 섞여 생기던 가죽끈과 금속의 과도한 변형을 제거했다.
- 카라 안쪽은 목 본을 따라가도록 높이와 웨이트를 조정해, 고개를 움직일 때 원래 뒷목 장식이 드러나지 않게 했다.
- FBX는 두께를 적용한 의상 파트를 합쳐 `-Y Forward / Z Up`, 단위 변환 적용, leaf bone 추가 없음, 애니메이션 없음으로 내보냈다. Blender 미터 단위를 UE 센티미터 변환에 맞춘다.
- 향후 UE 적용 시 이 의상의 몸체 가림 범위와 기존 스켈레톤·손목 후처리 설정을 유지해야 한다. UE 임포트, 게임 장착, 의상 교체 시스템, 천 물리, LOD는 이번 범위에 포함하지 않는다.

## 검증 범위

기존 운동복에서 독립 추출한 원래 메시 해시와 대조해 캐릭터 좌표 보존을 검사했다. 본 계층·레퍼런스 행렬, 표정·재질 연결, UV·웨이트·퇴화 면을 검사하고 타이틀 A/B/C를 각각 13프레임 평가했다. FBX를 빈 장면에 다시 가져와 본·형태·삼각형·재질·UV·웨이트를 비교했다. 두 검사 모두 오류 0건이며 FBX 좌표 오차는 0.000001m 미만이다. 이 검사는 모든 전투 동작의 관통이나 실제 UE 임포트까지 보장하지 않는다.

타이틀 B에서 왼팔 소매 안쪽이 깊게 접히는 압축 경고 1건이 남는다. 해당 모서리는 28.01mm에서 5.35mm로 접히며 렌더에서 구멍이나 찢어짐은 보이지 않았다. 롤업 끝단, 손목 밴드·버클, 멜빵에서 발견한 웨이트 불연속은 수정해 별도 변형 경고를 해소했다. 앞목의 기존 장식 노출과 종아리·양말 사이의 틈도 수정 후 재검토했다.

일회성 생성·내보내기·검사 스크립트와 중간 모델 파일을 제거한 뒤 동일한 검사를 메모리에서 다시 실행해 통과했다. 후속 편집은 저장된 Blender 원본에서 진행한다.

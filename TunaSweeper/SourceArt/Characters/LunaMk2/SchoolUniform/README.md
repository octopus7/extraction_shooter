# LunaMk2 교복 의상

남색 긴소매 블레이저, 아이보리 세일러 카라, 버건디 리본과 회청색 체크 주름 스커트다. 기존 캐릭터에 맞춘 별도 의상 모델이며 교체 시스템과 게임 적용은 포함하지 않는다.

## 파일

- `LunaMk2_SchoolUniform.blend`: 의상 22개 파트를 각각 편집할 수 있는 Blender 5.2 원본. 기존 캐릭터와 착용 미리보기를 함께 보관한다.
- `Models/SKM_LunaMk2_SchoolUniform.fbx`: 의상만 합친 스켈레탈 메시. 6,048정점, 12,044삼각형, 머티리얼 슬롯 5개, 기존 뼈 130개를 포함한다. 몸체, 머리, 기존 메이드복과 애니메이션은 이 FBX에 포함하지 않는다.
- `Textures/T_LunaUniform_Plaid_BaseColor.png`: 반복 가능한 1024×1024 체크 텍스처. 나머지 재질은 단색이다. FBX는 이 파일을 상대 경로로 참조하며 Blender 파일에는 텍스처를 패킹했다.
- `Previews/`: 앞·뒤·사선·상세와 기존 타이틀 A/B/C 포즈 렌더.
- `blender_validation.json`, `fbx_validation.json`: 최종 저장 파일 및 FBX 재읽기 검사 결과.

## Blender 구성

| 컬렉션 | 내용 |
| --- | --- |
| `00_Original_Maid_Preserved` | 원래 캐릭터, 메이드복과 타이틀 스커트의 보존 사본. 기본적으로 숨겨져 있다. |
| `01_Character_Preview` | 교복 착용을 확인하는 캐릭터 사본과 `SK_LunaMk2_Uniform` 리그. |
| `02_SchoolUniform_Export` | 새 교복 파트. 공통 리그를 따르며 각 파트를 독립적으로 편집할 수 있다. |
| `03_Preview_Studio` | 확인용 카메라, 조명과 바닥. |

원래 모습을 보려면 01·02 컬렉션을 숨기고 00 컬렉션의 뷰포트/렌더 숨김을 해제한다. 교복용 몸체의 `SchoolUniform_BodyCoverage_Reversible` Mask를 끄면 가려 둔 원래 몸체 정점과 메이드 장식이 복원된다. 원본의 머리카락과 연결된 헤드밴드도 보존했다.

몸체와 메이드 상의 일부는 원래 하나의 표면과 텍스처다. 따라서 교복용 사본에서 `Uniform_VisibleBody` 정점 그룹으로 덮이는 몸체와 장식을 숨겼다. 이후 게임에 적용할 때는 이 가림 처리를 반영한 몸체를 함께 사용해야 한다. 이번 작업은 피부 텍스처를 새로 만들거나 원래 몸체를 삭제하지 않는다.

## 리깅과 향후 적용

- 기준은 `Blender/SKM_LunaMk2.blend`에서 파생된 `../TitleMotions/LunaMk2_TitleMotions.blend`다. 기존 소스와 `/Game/Characters/Player/LunaMk2/` 에셋은 변경하지 않았다.
- 교복 리그는 원래 `SK_LunaMk2`의 130개 본 이름·계층·레퍼런스 행렬을 그대로 유지한다. 추가 의상 본은 없다. 얼굴의 기존 표정 6개도 미리보기 사본에 유지한다.
- FBX는 `-Y Forward / Z Up`, 단위 변환 적용, leaf bone 추가 없음, 애니메이션 내보내기 없음으로 저장했다. 메시를 합치고 옷 두께를 적용한 뒤 내보냈다.
- 스커트는 pelvis와 좌우 thigh에 웨이트를 주었다. 천 시뮬레이션, 충돌 보정, 교체 UI, 런타임 장착 코드는 구현하지 않았다.
- UE에서 가져오기와 모든 전투 동작의 착용 검사는 후속 적용 단계에서 필요하다. 기존 스켈레톤과 `ABP_LunaMk2_WristPostProcess` 설정은 그때 유지해야 한다.

## 검증 범위

최종 Blender 파일의 본 행렬 일치, 표정 좌표 보존, UV, 정규화 웨이트와 유효한 메시를 검사했다. 기존 타이틀 A/B/C 동작을 각각 13프레임씩 평가했고 앞·뒤·사선 및 포즈 렌더를 확인했다. FBX를 빈 Blender 장면에 다시 가져와 메시 수, 130개 본 계층, 정점 범위, 본 위치, 삼각형 수와 웨이트를 검사했다. UE 가져오기 및 천 물리 검증은 수행하지 않았다.

제작용 임시 생성기와 자동 재생성 경로는 결과물에 포함하지 않는다. 후속 수정은 저장된 Blender 파일에서 진행한다.

# LunaMk2 우비

[사용자 레퍼런스](References/Raincoat_Reference.png)를 바탕으로 만든 일곱 번째 착용 의상이다. 광택 있는 노란 A라인 우비, 내려진 후드, 앞 라펠과 스냅, 두 플랩 주머니, 뒤 요크, 손목 탭, 흰 카라와 붉은 리본이 있는 아이보리 원피스, 분홍 고무장화로 구성했다. 우산이나 손에 드는 소품은 포함하지 않는다.

## 편집 원본과 출력

- `LunaMk2_Raincoat.blend`: Blender 5.2 원본. 의상 80개 파트, 원래 130본 리그와 얼굴 표정·헤어를 보존한다. 새 의상에는 이미지 텍스처 없이 단색 PBR 재질 10개를 사용한다.
- `Models/SKM_LunaMk2_Raincoat.fbx`: 의상만 합친 메시. 56,298정점, 112,340삼각형, 재질 10개, 본 130개.
- `materials.json`: 재질의 선형 색상·거칠기·금속성 값.
- `Previews/`: 정면·사선·후면과 타이틀 A/B/C 포즈 렌더.
- `blender_validation.json`: 각 편집 메시와 39개 포즈 샘플의 검증 결과.
- [런타임 에셋·검증](../RuntimeOutfits/Raincoat/): 몸체와 의상 FBX, UE 임포트·재읽기·Leader Pose 검증, 실제 UE 캡처.

기존 Sportswear의 캐릭터 사본과 소매 구조를 바탕으로 만들었다. 원래 몸체 좌표, 얼굴 표정, 헤어, 본의 이름·계층·레퍼런스 행렬은 유지한다. 기존 Blender 파일, UE 원본·기존 의상은 덮어쓰지 않는다.

`SKM_LunaMk2_RaincoatBase`의 `Raincoat_BodyCoverage_Reversible` Mask를 끄면 가려진 몸체가 복원된다. 새 옷 안의 몸체, 원래 메이드 장식과 신발은 숨기고 목·손·무릎·장화 위 다리를 표시한다. 목은 완성된 Adventurer의 원본 장식 제외 마스크를 사용하며, 새 흰 카라 밴드는 목 움직임을 따라간다. 원래 메이드 의상을 보려면 01·02를 숨기고 00의 숨김을 해제한다.

## 리깅과 검증

의상 정점은 최대 3개 본의 정규화된 가중치를 가진다. 몸통은 높이에 따라 spine 본을 보간하며, 긴 밑단은 pelvis와 양쪽 thigh를 부드럽게 혼합한다. 소매는 기존 팔 가중치를 유지하고 손목 탭·스냅은 전완 twist 본의 일정한 혼합을 사용한다. 장화는 종아리에서 발 본으로 연속적으로 연결한다.

두께 면까지 적용한 편집 메시의 UV를 펼쳤다. 각 파트의 비다양체 모서리·느슨한 정점·퇴화 삼각형·면적 0 UV 삼각형은 모두 0개다. 삼각형 면적은 `calc_loop_triangles`로 검사했다. 타이틀 A/B/C 각각 13프레임, 총 39개 샘플에서 퇴화 삼각형과 2.5배 초과 모서리 늘어남 경고가 없다. 전후면과 세 포즈의 렌더도 검토했다.

런타임 Base는 Mask를 적용한 몸체·Eye·Head·SideTail이며 Face는 제외한다. UE의 기존 얼굴 컴포넌트는 그대로 유지한다. 몸체의 원래 최대 7개 본 영향은 상대 비율을 보존하여 정규화했다. Base는 기존 물리 에셋과 손목 후처리 AnimBP를 사용하고 Clothing은 Base의 Leader Pose를 따른다.

FBX는 센티미터 좌표, `-Y Forward / Z Up`, 애니메이션·추가 leaf bone 없이 내보냈다. 기존 스켈레톤을 지정해 임포트한 실제 UE 130본 기준 변환의 최대 차이는 위치 0.002043cm, 회전 0.007494도, scale 0.00000936이다. 새 프로세스에서 메시·재질·가중치 참조를 다시 확인했다.

UE의 A/B/C 39개 샘플에서 실제 손 위치 변화가 확인되며, Base와 Clothing의 130개 본 변환이 일치한다. 천 물리와 추가 LOD는 만들지 않았고 모든 전투·이동 모션의 관통을 검증한 것은 아니다. 일회성 생성 스크립트는 검증 후 제거한다. 이후 편집은 이 Blender 원본에서 진행한다.

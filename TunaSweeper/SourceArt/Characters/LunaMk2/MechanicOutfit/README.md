# LunaMk2 정비사 작업복

주황색 멜빵 작업복, 남색 반소매 이너, 큰 가슴 주머니, 무릎 보강천, 공구 벨트와 짧은 작업 부츠를 조합했다. 한쪽 파우치에는 렌치와 드라이버를 달았다. 기존 메이드복·교복과 별도로 보관하는 교체용 의상 원본이다.

## 결과물

- `LunaMk2_MechanicOutfit.blend`: Blender 5.2 편집 원본. 의상과 봉제선·버클·공구·부츠 끈을 포함한 88개 파트를 구분했다.
- `Models/SKM_LunaMk2_MechanicOutfit.fbx`: 의상·부츠·공구만 합친 스켈레탈 메시 1개. 12,718정점, 25,084삼각형, 재질 슬롯 8개, 본 130개. 캐릭터 몸체·머리와 애니메이션은 포함하지 않는다.
- `Previews/`: 앞·뒤·사선·상세 및 기존 타이틀 A/B/C 착용 포즈 렌더.
- `materials.json`: 새 의상의 단색 PBR 재질 값. 캐릭터 참고용 텍스처는 Blender 파일 안에 패킹되어 있다.
- `blender_validation.json`, `fbx_validation.json`: 최종 파일의 구조와 FBX 재읽기 검사 결과.

| 컬렉션 | 내용 |

| `01_Character_Preview` | 작업복 착용용 몸체 사본과 `SK_LunaMk2_Mechanic` 리그. |

| `03_Preview_Studio` | 미리보기 카메라·조명·바닥. |

`../SchoolUniform/LunaMk2_SchoolUniform.blend`의 검증된 캐릭터 사본을 바탕으로 제작했다. 원래 `Blender/SKM_LunaMk2.blend`, 타이틀 모션 원본, 교복 원본과 UE 캐릭터 에셋은 수정하지 않았다. 얼굴·머리카락·머리 장식도 보존했다.

원래 모습을 보려면 01·02 컬렉션을 숨기고 00의 뷰포트/렌더 숨김을 해제한다. 작업복용 몸체의 `Mechanic_BodyCoverage_Reversible` Mask를 끄면 원래 몸체 전체가 복원된다. `Mechanic_VisibleBody` 그룹은 목과 노출된 팔·손을 표시하고, 의상과 부츠로 덮인 원래 몸체·신발 및 메이드 장식을 가린다.

## 리깅과 사용 조건

- 원래 `SK_LunaMk2`와 같은 130개 본 이름·부모 계층·레퍼런스 행렬을 사용한다. 본을 추가하지 않았으며 기존 얼굴 표정 6개도 유지한다.
- 바지는 원래 하체 메시에서 파생해 thigh/calf twist 본을 포함한 웨이트를 유지했다. 원본 허리 뒤쪽의 미세한 내부 면 1개는 작업복 사본에서만 제거했다.
- 멜빵·상의는 몸통을, 바지와 무릎 보강천은 원래 하체 웨이트를 따른다. 부츠는 foot/calf/ball을 혼합해 발과 발목을 따라간다. 공구와 파우치는 pelvis에 고정된 외형이다.
- FBX는 `-Y Forward / Z Up`, 단위 변환 적용, leaf bone 추가 없음, 애니메이션 없음으로 내보냈다. 두께를 적용하고 의상 파트를 합친 상태다.
- 향후 UE에 적용할 때는 몸체 가림 처리를 함께 반영하고 기존 스켈레톤·손목 후처리 설정을 유지해야 한다. 이번 작업은 UE 임포트, 게임 장착, 의상 교체 시스템, 공구 기능, 천 물리를 포함하지 않는다.

## 검증

본의 레퍼런스 행렬과 얼굴 표정 좌표가 보존되는지, 모든 의상 파트의 웨이트·UV·좌표와 메시 연결이 유효한지 검사했다. 기존 타이틀 A/B/C를 각각 13프레임씩 평가하고 렌더를 검토했다. FBX를 빈 장면에 다시 가져와 본 계층·정점 범위·삼각형 수·정규화 웨이트를 확인했다. 이 검증은 모든 전투 동작의 충돌이나 UE 임포트 검증을 대신하지 않는다.

임시 모델 생성기와 내보내기 스크립트는 검증 후 제거했다. 후속 편집은 저장된 Blender 원본에서 진행한다.

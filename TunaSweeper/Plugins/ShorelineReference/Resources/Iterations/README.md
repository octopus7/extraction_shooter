각 폴더의 `manifest.json`에는 카메라, 셰이더 시각, 파라미터와 파일 해시가 있다. `analysis.json`에는 해당 시점의 자동 검사 결과가 있으며, 시각적 판단은 위 표를 함께 본다. `captured`는 촬영 완료만 뜻한다. `render.log`는 재분석을 위한 실행 로그 사본이다. 초기 01 단계는 소스 해시만 있으며, 나머지 단계는 `shader_source.hlsl` 사본도 보존한다.

최신 분석 도구는 저장된 로그 사본을 먼저 사용하므로 프로젝트 `Saved` 폴더 없이도 이미지 분석을 재실행할 수 있다. 초기 단계에 없었던 글린트 A/B는 초기 스키마에 요구하지 않는다. 기준 화면이나 실패한 시안에서 검사가 실패하는 것은 보존한 실험 결과다.

UE PNG 내보내기가 IEND 뒤에 남긴 여분 바이트는 제거했다. 정상 PNG 청크와 디코딩 픽셀은 바뀌지 않았다. 초기 92장의 전후 픽셀 동일성은 `png_container_validation.json`, 원래 파일 해시는 각 manifest의 `original_export_sha256`에 기록했다. 원래 컨테이너 파일은 `Saved/ShorelineVisualIteration/OriginalPngContainers`에 별도 보존했다.

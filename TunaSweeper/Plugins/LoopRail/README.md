# Loop Rail

UE 5.7용 순환 지상열차 플러그인. 게임 모듈을 참조하지 않는다. 런타임 의존성은 Core, CoreUObject, Engine이고, 모든 전용 콘텐츠는 `/LoopRail` 안에 있다. 다른 프로젝트로 `Plugins/LoopRail`을 복사해 사용할 수 있다.

## 바로 확인하기

콘텐츠 브라우저에서 **Show Plugin Content**를 켜고 `/LoopRail/Maps/LoopRailPreview`를 연다. 폐순환 선로, 기관차 1량 + 객차 3량, 정차역 2개, 건널목 1개가 들어 있다. PIE에서는 호스트 프로젝트의 기본 GameMode가 플레이어를 생성한다. 플러그인 맵에 특정 게임의 GameMode나 캐릭터 참조는 저장하지 않는다.

플레이어는 승강장 위에서 시작한다. 객차 양 끝의 측면 출입구로 걸어 들어가면 된다. 중앙 통로와 차량 사이 연결 발판으로 다음 객차까지 걸어서 이동할 수 있다. 좌석은 충돌이 있는 외형이며 앉기 상호작용은 없다. 기본 정차 시간은 샘플 역에서 12초다. 레벨 재시작 시 `StartDistance`에서 운행을 다시 시작한다.

## 레벨에 배치하기

1. **Loop Rail Track** 액터를 배치하고 `RailPath` 스플라인을 편집한다. 폐순환을 유지하고 액터 스케일은 1로 둔다. 선로의 방향이 진행 방향이다. 기본 궤간은 150cm다.
2. **Loop Rail Train**을 배치하고 `Track`에 선로를 연결한다. `VehicleCount`는 기관차를 포함한 총 차량 수이며 기본 4, 범위 1–16이다. `VehicleGap`은 기본 80cm다. `StartDistance`는 선로 시작점부터 기관차 중심까지 거리다. `RebuildTrain`으로 편집기 미리보기를 갱신할 수 있다.
3. **Loop Rail Station**을 선로 근처에 놓고 `Track`을 연결한 뒤 `AlignToTrack`을 누른다. 액터 원점이 기관차 중심의 정차 위치다. `DwellSeconds`, `PlatformLength`, `PlatformWidth`, `bPlatformOnRight`를 조절한다. 기존 승강장을 쓰면 `bShowPlatform`을 끈다. 승강장은 직선 구간에 놓는다.
4. **Loop Rail Crossing**을 건널목 위치에 놓고 같은 `Track`을 연결한 뒤 `AlignToTrack`을 누른다. 접근 거리와 속도에 따라 경고등·차단기가 작동하며, 마지막 객차와 `RearClearance`가 지나간 후 열린다. `WarningSound`에 반복 가능한 경고음을 지정할 수 있다. 기본 사운드 파일은 포함하지 않는다.

선로 형태를 바꾼 뒤 열차의 `RebuildTrain`, 역·건널목의 `AlignToTrack`으로 배치를 갱신한다. 너무 짧거나 열린 선로에서는 운행하지 않는다. 기본 4량 편성의 전체 길이는 38.4m이고, 선로는 편성 길이보다 최소 1m 길어야 한다. 급커브에서는 차체가 선로 안쪽으로 들어오므로 주변 구조물과 충분한 간격을 둔다.

## 외형과 교체 규격

| 항목 | 규격 |
|---|---|
| 차량 본체 | 길이 900cm, 폭 220cm |
| 좌표 | +X 전방, +Z 위, 원점은 차량 중심의 레일 상면 |
| 바닥 | 레일 상면에서 60cm |
| 객차 좌석 | 8열 × 좌우 1석, 총 16석 |
| 좌석 폭 / 중앙 통로 | 50cm / 90cm |
| 앞뒤 출입구 공간 | 객차 양 끝 약 1m 이상 |
| 기관차 메시 | 4,916삼각형, 장식 굴뚝 1개 |
| 객차 메시 | 본체 9,012 + 선택 지붕 188 = 총 9,200삼각형 |
| 연결 발판 | 폭 100cm, 난간 안쪽 92cm, 396삼각형 |

차체는 청록색·크림색, 테두리는 황동색, 좌석은 목재로 표현했다. 큰 윤곽과 창틀·손잡이에 형상을 쓰고 패널 이음선, 환기구, 체결부, 나무결과 마모는 UV 아일랜드별 고유 텍스처에 배치했다. 차량별 2K BaseColor·Roughness·Metallic 텍스처를 `/LoopRail/Textures`에서 사용한다. BaseColor만 sRGB이며 나머지는 선형 데이터다. 메시마다 재질 슬롯 하나를 사용한다.

편집 원본·FBX·UV 대응표와 재수입 검증 자료는 프로젝트의 `SourceArt/LoopRail`에 있다. 런타임에는 저장된 플러그인 에셋만 필요하다. 현재 기본 모델의 검사 예산은 기관차 12,000삼각형, 객차와 지붕 합계 16,000삼각형이다. 이동 차량이므로 자동 라이트맵 UV 생성을 사용하지 않는다.

`LocomotiveMesh`, `CarriageMesh`, `CarriageRoofMesh`를 교체한다. 같은 원점과 실측 규격을 사용한다. 바닥은 별도 `UBoxComponent`이므로 메시 교체 후에도 탑승용 이동 바닥이 유지된다. 교체 메시에는 좌석·벽 충돌을 만들고 통로와 출입구를 비워 둔다. 기본 메시의 바닥 충돌은 별도 바닥 컴포넌트가 담당한다.

`ConnectionMesh`는 차량 사이 발판이다. 교체 규격은 길이 100cm(+X)·폭 100cm, 바닥 윗면 중심이 원점, 바닥 아랫면 Z=-10cm다. 양쪽 난간은 Y=±46~50cm, 높이 90cm다. 차량 두 끝의 실제 위치를 연결하도록 길이와 방향을 갱신하며 양쪽 바닥에 20cm씩 겹친다. 발판과 난간 충돌은 플러그인이 별도 상자로 제공하므로 연결 메시에는 충돌을 넣지 않는다. 기본 4량에는 연결부 3개가 생긴다. 객차 끝 난간의 중앙 90cm를 열어 중앙 통로가 이어진다. 기관차는 뒤쪽 발판까지만 접근할 수 있다.

`bShowCarriageRoofs`는 기본 false로, 탑다운에서 캐릭터와 좌석이 보이도록 했다. true이면 별도 지붕 메시가 추가된다. 기관차는 운전실 내부나 운전 조작을 제공하지 않는다.

## 게임 연결

- `SetRunning`으로 운행을 켜고 끈다. false는 즉시 정지하며 정차 타이머도 보존한다.
- `OnStationArrived`, `OnStationDeparted`, `OnWarningChanged`로 게임 쪽 연출을 연결한다. 역 이벤트는 서버에서 발생한다.
- 탑승은 엔진 `ACharacter`의 이동 바닥 처리를 사용한다. 앉기, 강제 부착, 별도 탑승 UI를 요구하지 않는다.
- 충돌은 기본 차체·좌석·바닥·연결부의 BlockAllDynamic이다. 충돌 피해, 장애물 감지 제동, AI 탑승은 이번 범위에 포함하지 않는다.
- 속도·위치는 서버에서 운행하며 클라이언트에 복제한다. 다중 클라이언트의 실제 네트워크 탑승은 별도의 프로젝트 통합 검증이 필요하다.
- 운행 상태는 레이드마다 초기화하며 세이브 필드를 추가하지 않는다. UI 문구는 추가하지 않았다.

## TunaSweeper 탑승 카메라

게임의 `ATunaSweeperTopDownCharacter`가 이동 바닥의 소유자를 확인해 자신이 탑승한 열차의 속도와 정차 상태를 읽는다. 로컬 플레이어가 움직이는 열차 위에 있을 때 현재 카메라 모드 거리의 1.6배로 넓어진다. 정차·운행 중지·하차하면 원래 거리로 부드럽게 돌아간다. 기본 모드는 1,200cm에서 1,920cm, 탑다운은 1,500cm에서 2,400cm, 낮은 전면 시점은 650cm에서 1,040cm로 바뀐다.

캐릭터 기본값의 `Camera|Train`에서 `MovingTrainCameraDistanceMultiplier`와 `TrainCameraInterpSpeed`를 조정한다. 기본 보간 속도는 3으로 약 1초에 걸쳐 전환하며, 기존 카메라 보간도 적용된다. 인벤토리나 대화로 조작이 잠겨도 열차 거리 변화는 계속 반영된다. 카메라 모드, FOV, 각도와 조준 오프셋은 기존 동작을 유지한다.

이 연결 코드는 게임에 있으며 의존 방향은 TunaSweeper → LoopRail이다. 플러그인은 게임 카메라를 참조하지 않으므로 다른 프로젝트에서는 해당 프로젝트의 카메라에 같은 방식으로 연결하면 된다. 카메라 배율은 런타임 상태이며 저장하지 않는다.

## 검증

`LoopRail.` 자동검사: 역 정차·출발, 정지, 편성 변경, 열린 선로 거부, 건널목 후미 판정, 캡슐 통로·출입구 통과, 16석 충돌, 이동 바닥 탑승, 연결부 생성·제거, 정차·곡선 주행 중 차량 간 왕복, 복제된 정차 상태, 저장 맵 재로드, 프로젝트 역참조 금지, 차량 삼각형 예산, FBX와 저장 메시의 삼각형 수 일치, UV 범위, 2K 텍스처와 색공간. `LoopRail.Visual.Blockout`은 RHI가 활성화된 실행에서 `Saved/LoopRail/Preview`에 전체 편성·기관차·객차·지붕·직선/곡선 연결부 렌더 이미지를 저장한다.

게임의 `TunaSweeper.Player.Camera.TrainRide` 검사는 세 카메라 모드에서 운행·정차·하차, 운행 중 모드 변경, 입력 잠금 중 정차·출발, 로컬 제어 해제와 FOV·각도 유지를 확인한다.

`Tests/MotionTests.cpp`는 실제 런타임의 `LoopRailMotion.h`를 사용하며 C++17 컴파일러로 실행할 수 있다. 순환 경계, 후미 점유, 가속·제동 및 프레임 지연 시 정차 위치 초과를 검사한다.

에셋 생성 코드는 최종 소스에 남기지 않는다. 저장된 에셋을 사용하므로 시작 시 재생성하지 않는다.

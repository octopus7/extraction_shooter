# 적 로봇 4종 레퍼런스 v01

이 폴더의 PNG는 실제 ImageGen으로 생성한 디자인 참고 이미지다. 기구 도면이나 가동 검증을 마친 메시가 아니다. 후속 사용자 지시에 따라 이 디자인을 모델링한 실제 산출물은 `ArtSource/RobotFamily/20260906_v01`에 있다.

## 디자인과 확인

| ID | 역할 초안 | 다리 | 실루엣과 관절 |
|---|---|---:|---|
| Q1 Scout | 정찰 | 4 | 길고 좁은 쐐기 몸통, 가는 상·하부 링크, 원형 발 |
| Q2 Bulwark | 돌격·방어 | 4 | 낮고 넓은 장갑 몸통, 굵은 짧은 링크, 사각 발 |
| H1 Carrier | 지원·운반 | 6 | 긴 장비 상자 몸통, 좌우 앞·중간·뒤 3쌍, 원형 발 |
| B1 Sentry | 경계 | 2 | 세로형 포드에 다리만 연결, 역관절 링크, 긴 사각 발 |

- `comparison_reference.png`: 최종 비교 이미지. 직접 관찰하여 Q1 4, Q2 4, H1 6, B1 2개의 다리/발을 확인했다. 서로 다른 뷰와 배율이므로 치수 비교용이 아니다.
- `q1_reference.png`, `q2_reference.png`, `h1_reference.png`, `b1_reference.png`: 각각 본체 사선뷰, 평면뷰, 독립 다리 구조도. 평면뷰에서 4·4·6·2개의 체인을 확인했다.
- 개별 시트의 LF/RF/LR/RR 표기는 센서 방향과 반대로 생성된 곳이 있어 **앞뒤 본 이름의 근거로 사용하지 않는다**. 센서가 있는 쪽을 +X 전방으로 사용한다.
- H1 사선뷰는 먼 쪽 발 일부가 몸통에 가려져 있다. 해당 시트의 평면뷰 및 최종 비교 이미지의 3쌍 배치를 구조 기준으로 삼았다.
- 전체뷰의 링크 길이와 독립 다리 그림은 완전히 일치하지 않는다. 실제 모델은 독립 다리 그림의 분리된 Upper → Lower → Foot 구조와 명확한 중간 무릎을 우선했다.
- 최초 비교 초안 및 중간 수정본은 H1의 다리 수가 틀려 채택하지 않았다. 최종 비교본은 세 번의 후속 수정/생성을 거쳐 직접 재확인했다.

## 미술 근거

`YT/OneEyeBot.jpg`의 밝고 단순한 외장·원형 센서와 `GeneratedImages/Props/WaterIntake/water_intake_reference_v01.png`의 산업 구조를 확인했다. `Docs/SSOT/TunaSweeper_SSOT_Quest_Item_v0.6.md`의 이미지 스타일 가이드에서 단순한 하이라이트와 낮은 부품 복잡도를 참고했다. 아이템 아이콘 규칙 전체를 로봇 제작 규칙으로 간주하지는 않았다.

공통 팔레트는 아이보리 외장, 청회색 링크, 검은 원통 관절, 주황 표식과 주황 센서다. 인간 얼굴·팔·흉곽·목을 두지 않았다. 배선이나 연결 장식이 관절을 가로지르지 않도록 구성했다. 역할은 시각 디자인 초안이며 AI 데이터 변경은 없다.

## 생성 기록

- 도구: built-in `image_gen.imagegen`, imagegen 스킬.
- 최초 프롬프트: `prompts.md`.
- 개별 이미지·텍스처·비교본 수정 프롬프트: `prompt_set.md`.
- `robot_atlas_imagegen_source.png`: 1254×1254 실제 생성 원본. 모델에 사용한 최종 텍스처는 원본을 변경하지 않고 복사했다.

# 검증·성능 기록

측정 자료는 `TunaSweeper/SourceArt/Environment/LabSupplyProps/`의 JSON 보고서다. 삼각형과 인스턴스 수는 실제 매니페스트 및 임포트 메시 기준이며 FPS, PIE 플레이, GPU 시간은 측정하지 않았다.

| 단계 | 확인 결과 / 남은 검증 |
|---|---|
| Blender 원본 + FBX 독립 재로드 | `source_validation.json`: 12종 통과. 최종 싱크대 전면 UV 수정 후 독립 재검증 통과 |
| UE 임포트 | `unreal_import_validation.json`: UE 5.7.4, 12종 통과 |
| UE 새 프로세스 에셋 재로드 | `unreal_reload_validation.json`: 12종 통과. 최종 UV 재임포트 후 전체 에디터 새 프로세스 검사 통과, 종료 코드 0 |
| 전용 맵 생성 | `unreal_map_creation.json`: 저장 성공, 두 공간·106개 배치·카메라 4개·스케일 프록시 2개 |
| UE 전체 에디터 새 프로세스 맵 재로드·충돌·가림 | 종료 코드 0. 저장 맵 충돌 11회와 중앙 동선 카메라 시야 48회 모두 통과 |
| 최종 렌더 시각 검수 | 12종 시트·개별 모델·두 공간·오염 비교 제공. 최종 싱크대 전면·수조 및 12종의 타일 배치를 직접 시각 확인 |

원본 검증은 정확한 치수·바닥/후면 피벗·단위 변환, 연결된 각 솔리드의 매니폴드·양의 체적·유효 노멀, 퇴화 삼각형 부재를 검사한다. UV0의 0–1 범위와 타일 여백, 면 UV 면적, UV1의 미터/2 좌표, 활성 SurfaceParams의 네 채널과 타일별 금속성·거칠기를 검사한다. FBX를 다시 읽어 Y축/면 보정을 되돌리고 같은 검사를 반복하며 단순 충돌 박스의 개수·치수도 대조한다. FBX 색상은 내보내기·재로드 모두 Linear다.

기록된 FBX 메시 최대 경계 오차는 **5.97×10⁻⁸m 미만**, 충돌 박스 최대 경계 오차는 **1.15×10⁻⁷m 미만**이다. UE 보고서는 모델별 삼각형·재질 슬롯·경계·충돌 개수·각 박스 경계/회전, UV와 버텍스 색상 임포트 설정을 검사했다. Nanite는 사용하지 않는다. 최종 UV 수정 뒤 갱신한 보고서가 최종 판정 자료다.

## 비용과 배치 합계

| 범위 | 메시 인스턴스 | 삼각형 | 구성 |
|---|---:|---:|---|
| 고유 신규 모델 | 12 | 2,368 | 모델별 재질 슬롯 1, 단순 충돌 박스 총 140 |
| 연구소 샘플 | 44 | 3,876 | 신규 소품 13개·3,424삼각형 + 기존 실내 31개·452삼각형 |
| 보급 창고 샘플 | 62 | 5,188 | 신규 소품 31개·4,736삼각형 + 기존 실내 31개·452삼각형 |
| 두 공간 합계 | **106** | **9,064** | 스케일 프록시 2개·조명·카메라 제외 |

신규 재질은 Opaque 하나이고 연결된 텍스처 샘플은 **2개**다. 아틀라스 **2048×2048**, 재사용 오염 마스크 **1024×1024**이며 UE 임포트 크기를 실제 확인했다. R 금속성/G 거칠기의 버텍스 색상과 Custom Primitive Data 오염 강도·크기·위치 조절을 사용한다. 위 수치는 드로콜·FPS 추정치가 아니다.

## 카메라와 가림 검사의 범위

전용 두 공간은 각각 8×8m이며 창고는 연구소에서 X방향 12m 떨어진다. 천장·보·기둥 없이 기본 실내 모듈을 재사용한다. 높은 선반을 벽면으로 배치하고 중앙 동선을 비운다. 프로젝트 탑다운 설정인 암 길이 **1500cm**, 피치 **-88°**, 요 **0°**, FOV **70°**를 프리뷰에 적용한다. UE 검증기는 프로젝트 기본 카메라 설정과 이를 대조하고 동선의 여러 지점을 단순 충돌 트레이스로 검사한다. 48개 검사 지점에서 중앙 동선 가림이 없었고, 틈과 받침면의 충돌 11회 검사도 통과했다.

Blender 인물 표식은 폭 약 **50cm**의 두 원기둥으로 만든 대략적인 스케일 프록시다. UE 인물 표식은 **68×68×176cm** 크기를 맞춘 프록시다. Blender 표식을 실제 캐릭터 캡슐과 동일하다고 보지 않으며, 정적 시야/충돌 검증을 실제 플레이 검증으로 확대 해석하지 않는다.

선반의 1.30×.50m 내부와 .545m 수직 여유에 .60×.40×.40m 상자 두 개가 들어간다. 팔레트와 박스 묶음은 상면 높이 .15m로 맞추고, 트레이는 작업대 .90m 및 카트 .735m에 얹는다. 샘플 맵의 적재 조합, 빈 선반·팔레트·싱크의 실제 틈과 충돌 트레이스는 최종 UE 맵 재로드 보고서로 확인한다.

검증된 원본과 UE 에셋은 별도 로컬 커밋으로 기록한다. 일회성 UE 생성기는 애셋과 함께 커밋한 직후 제거하고 다음 커밋으로 정리한다. 원격 push는 하지 않는다.

기존 Niagara NE_PostProcess의 Typed Element Registry ensure로 최초 null-RHI commandlet은 애셋 검사를 통과하고도 종료 코드 1이었다. 프로젝트 코드는 변경하지 않고, 읽기 전용 Assets 검증을 전체 에디터 방식으로 실행하여 최종 종료 코드 0을 확인했다. 런타임 상주 텍스처 크기는 비동기 로딩 시 0일 수 있어 PNG IHDR과 UE의 source 기반 built size를 비교한다.

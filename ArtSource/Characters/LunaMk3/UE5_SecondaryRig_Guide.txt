LunaMk3 / UE 5.7 secondary rig handoff

현재 상태
- 기존 몸체 리그 61본에 흔들림용 48본을 추가한 총 109본.
- 양갈래 각각 4본, 늘어진 리본 각각 2본, 치마 둘레 12방향에 각 3본.
- 원본 몸체 본 이름/계층/기준 자세와 몸체 웨이트 유지.
- 얼굴, 두피, 머리띠, 리본 매듭은 head에 고정. 앞머리 전체를 흔드는 리그는 포함하지 않음.
- 키는 장식과 신발 포함 약 150.9cm. Blender 단위 m, FBX 실제 크기 확인 완료.
- 모델 FBX에는 애니메이션 없음. QA_LunaMk3_SecondarySway.fbx는 별도 3초 반복 변형 확인용 클립이며 보행이나 물리 시뮬레이션이 아님.
- 치마는 허리 아래를 차등 수축한 형태로 수정. 중간 폭 약 20~22%, 밑단 약 15% 축소. 상단 허리·UV·면 구성·스킨 웨이트 유지, 치마 본의 기준 위치만 형태에 맞춰 이동.
- 좁아진 치마의 QA 클립은 1단 체인을 고정하고 중간 진폭은 이전의 10%, 끝단은 80%로 조정. 저장된 73프레임 전체에서 몸과 치마의 교차 0을 확인했으며 UE 실시간 충돌 검증과는 별개다.

파일
SKM_LunaMk3.blend: 중립 자세 원본. QA_LunaMk3_SecondarySway 액션을 보존하지만 기본 연결은 해제.
SKM_LunaMk3.fbx: 텍스처 내장 Skeletal Mesh. 현재 LunaMk2 Skeleton과의 호환성은 검증하지 않았으므로 새 Skeleton으로 처음 가져오기 권장.
QA_LunaMk3_SecondarySway.fbx: 생성한 LunaMk3 Skeleton을 선택하고 애니메이션으로 가져올 테스트 클립.
secondary_physics_guide.json: 본 체인, 기준 위치(m), 초기 물리 설정 참고값.
secondary_rig_validation.json: 실제 본/웨이트/변형/FBX 재가져오기 검사 결과.

UE 적용 순서
1. FBX를 Skeletal Mesh로 가져오고 새 Skeleton 생성. Import Animations는 끄고 스케일 1을 유지. 크기 약 151cm와 109본을 확인.
2. 별도 secondary PhysicsAsset 구성. pelvis/head를 Kinematic 앵커로 두고 머리·상체·허벅지에 맞는 충돌 캡슐을 조정. hair_tail_*, hair_ribbon_* 본을 Simulated로 지정. 수축한 치마는 각 체인의 skirt_*_01을 Kinematic으로 유지하고 skirt_*_02, skirt_*_03부터 작은 범위로 움직이도록 시작한다.
3. 체인 간 연결의 선형 이동을 고정하고 회전 범위/스프링/감쇠를 조정. 본 사이 길이가 짧으므로 자동 생성한 큰 캡슐을 그대로 쓰지 말고 실제 머리끈/치마 표면에 맞게 축소. 치마 부피를 눌러 납작하게 만드는 과한 충돌은 피할 것.
4. 각 체인의 첫 본은 head 또는 pelvis에 제약으로 연결하고 다음 본은 직전 본에 연결. 같은 체인의 인접 캡슐과 이웃 치마 체인끼리의 충돌은 초기 설정에서 제외. 머리/몸/다리와의 충돌을 먼저 맞춘 뒤 필요한 충돌만 추가.
5. AnimBP에서 보행/몸 포즈 -> Local To Component -> RigidBody(전용 secondary PhysicsAsset) -> Component To Local -> Output으로 연결. 이미 같은 본을 움직이는 물리 노드가 있으면 중복 적용하지 않을 것.
6. 기존 LunaMk2 보행을 쓸 경우 별도 IK Retargeter에서 기준 포즈/비율을 맞추고 하체 접지를 점검. 이 파일은 기존 Skeleton으로 직접 호환된다고 보증하지 않음.
7. 정지, 걷기, 달리기, 급회전, 앉기, 텔레포트/리셋에서 검증. 관통이 있으면 캡슐/회전제한을 조정하고 큰 다리 보폭에는 별도 치마 포즈 보정이 필요할 수 있음.

주의할 범위
이번 작업은 메시의 본과 스킨 웨이트 작성 및 로컬 변형 검증이다. Unreal PhysicsAsset, AnimBP, 실제 게임 물리 연결/조정은 아직 수행하지 않았다. JSON의 물리 수치는 UE에서 튜닝할 시작값이며 검증된 완성 설정이 아니다.
프릴은 얇은 열린 천 표면이므로 UE의 M_LunaMk3_CleanWhiteCloth 재질에는 Two Sided를 활성화해 안쪽 면도 표시한다. 실제 작은 구멍과 잘못된 면 방향은 별도로 보수했으며, 기존 생성 모델의 일부 머리카락 표면과 속눈썹 페인트 불균형은 남아 있다. Tripo API 호출은 없다. 사용자 요청으로 눈 텍스처만 built-in image_gen에서 3회 생성했으며 최종 레퍼런스 기반 결과 1장을 사용한다.

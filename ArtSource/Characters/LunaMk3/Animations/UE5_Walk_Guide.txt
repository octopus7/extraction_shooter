LunaMk3 / 여성스러운 걷기 / UE 5.7 전달 파일

동작
- 30fps, 한 주기 1.2초. 소스 1~37프레임이며 37은 1과 같은 반복 경계 자세다.
- Blender 미리보기 재생 범위는 1~36으로 설정해 경계 자세의 중복 표시를 피했다.
- 좁은 발 간격, 작은 골반 좌우 이동과 회전, 반대 방향 팔 흔들림, 안정적인 상체를 적용했다.
- 보행 속도 72cm/s, 한 주기 이동 거리 86.4cm. 전방 +X, 위쪽 +Z.
- 머리카락의 작은 후속 흔들림과 치마의 다리 공간 확보 보정은 본 키로 구워져 있다. 실시간 천/머리카락 물리 시뮬레이션은 아니다.

파일
A_LunaMk3_Walk_Feminine_InPlace.fbx: 제자리 반복. 게임에서 캐릭터를 이동시키는 경우 사용.
A_LunaMk3_Walk_Feminine_RootMotion.fbx: root 본이 한 주기 동안 +X로 86.4cm 이동.
LunaMk3_Walk.blend: 수정 가능한 두 액션과 확인용 모델. InPlace가 기본 연결되어 있다. Preview_Only 컬렉션의 바닥은 FBX에 포함되지 않는다.
Previews/LunaMk3_Walk_ThreeQuarter.mp4: 사선에서 본 3주기 미리보기.
Previews/LunaMk3_Walk_Side.mp4: 옆에서 본 3주기 미리보기.
walk_validation.json: 접지, 루프, 몸-치마 교차, 골격/메시 보존 및 독립 FBX 재가져오기 검사 결과.

모델 변경
- 부모 폴더의 SKM_LunaMk3.blend/FBX도 함께 갱신했다.
- 기존 신발 뒤꿈치에 종아리/트위스트 웨이트가 섞여 발을 굴릴 때 약 16mm 가라앉는 문제가 있어 신발·발목 주변 650정점의 웨이트를 보정했다.
- z 0.08m 아래 신발은 foot/ball을 따르고 0.14m까지 원래 발목 웨이트로 부드럽게 연결한다. 최대 4본 영향과 정규화 유지.
- 메시 형태, UV, 재질, 109본의 이름/부모 관계/바인드 행렬은 유지했다. 기존 QA 액션도 중립 모델에 보존했다.

UE 적용 시
1. 수정된 SKM_LunaMk3.fbx를 사용한다. 기존 LunaMk3 Skeleton이 있으면 같은 골격에 갱신하고, 최초 도입이라면 모델에서 Skeleton을 만든다. LunaMk2 Skeleton에 직접 호환된다고 검증한 파일은 아니다.
2. 원하는 보행 FBX를 그 LunaMk3 Skeleton의 애니메이션으로 가져온다. 두 보행 FBX는 메시 없는 골격/애니메이션 파일이다. 임포트 시 기준 포즈를 보행 첫 프레임으로 덮어쓰지 않는다.
3. InPlace는 재생률 1에서 이동 속도 72cm/s에 맞춘다. 속도 변화에는 재생률/Stride Warping 등을 별도로 조정해야 한다. RootMotion은 UE에서 루트 모션을 사용하도록 설정하고 이동을 중복 적용하지 않는다.
4. 본 위치 키를 유지한다. 특히 pelvis, 팔 보정, skirt_* 위치 키를 Skeleton의 기준 위치로 강제하면 원본 동작 및 관통 보정이 사라진다. 이 전용 골격에서는 Translation Retargeting을 Animation으로 두고 먼저 원본 결과를 비교한다.
5. 치마와 머리카락의 구워진 키 위에 같은 본을 움직이는 RigidBody/AnimDynamics 등을 무조건 더하지 않는다. 실시간 물리를 도입한다면 해당 본의 구워진 동작과 교체/혼합하고 충돌을 다시 조정한다.
6. 이 결과는 한 종류의 직진 걷기다. 대기에서 걷기로 전환, 달리기, 옆/뒤 걷기, 회전, 경사면 Foot IK, AnimBP/BlendSpace 연결은 별도 작업이다.

검증 및 범위
- 73개 반 프레임 샘플에서 몸 전체(손·다리 포함)와 치마의 표면 교차 0.
- 평평하게 디디는 구간의 바닥 접점 이동 최대 약 0.18mm. 몸 메시 최저 높이 약 0.73mm로 지면 아래 침범 없음.
- 제자리 루프의 처음/끝 본 행렬 차이 0. 두 FBX의 재가져오기 후 109본을 5개 자세에서 비교해 최대 행렬 성분 오차 약 0.00000323.
- 모델 FBX도 별도 경로에서 외부 텍스처 검색 없이 재가져와 3메시, 109본, 이미지 13장 및 수정된 신발 웨이트 유지 확인.
- Blender FBX importer가 끝점이 닿는 본에 Connected를 자동 추정한다. 이 Blender 전용 제약은 위치 키를 억제하므로 재가져오기 검사에서는 해제했다. FBX 골격의 부모 관계는 변경하지 않았다.
- 애니메이션을 다시 내보낼 때 기본 노드 변환은 중립 자세여야 한다. 전달 FBX는 내보내기 범위 밖인 임시 0프레임에 중립 자세를 두고 1~37프레임만 구워 해결했다. 편집 원본의 보행 액션에는 임시 0프레임을 추가하지 않았다.
- Unreal Editor 가져오기, AnimBP 연결, 실제 게임에서의 루트 모션·충돌 검증은 아직 수행하지 않았다.
- Tripo 및 외부 생성 API 호출 0회. 추가 API 비용 0.

# 레이드 리프트 저작

## 아이템과 복구

- 고용량 콘덴서: 아이템 `6025`, UI 아이콘 `/Game/UI/Icons/T_UIIcon_HighCapacityCapacitor`.
- 리프트는 콘덴서 1개를 소비하여 복구한다. 부족하면 재료와 진행 상태를 바꾸지 않는다.
- 복구 상태는 기존 월드 진행 ID `world.passage.raid_lift`로 저장한다. 같은 ID를 사용하는 리프트는 복구 상태를 공유한다.
- 아이템은 재료 범주이며 자동 획득처를 추가하지 않는다. 루팅 저작은 별도다.

## 목적지

| 카드 | 이동 맵 | 시작 지점 그룹 |
|---|---|---|
| 숲 | `/Game/MainRaid/RaidForest` | Forest |
| 마을 동쪽 | `/Game/MainRaid/RaidVillage` | VillageEast |
| 마을 서쪽 | `/Game/MainRaid/RaidVillage` | VillageWest |
| 평원 | `/Game/MainRaid/RaidPlains` | Plains |

리프트 발판 위에서 상호작용하면 이미지 카드 4개가 열린다. 취소 또는 Escape로 닫는다. 선택 시에도 발판 위치를 다시 검사한다.

각 목적지 맵에 전용 레이드 PlayerStart를 여러 개 배치하고 위 그룹을 지정한다. 마을 동·서는 같은 맵에서 서로 다른 그룹을 사용한다. 선택한 그룹 안에서 무작위로 하나를 고르며 다른 그룹의 시작 지점으로 대체하지 않는다. 그룹이 비어 있으면 정상 도착할 수 없으므로 레벨 저작 시 반드시 배치해야 한다.

리프트로 고른 도착 그룹은 이번 이동에만 사용하는 메모리 상태이며 저장 슬롯에 기록하지 않는다. 레이드 사이의 인벤토리·체력·휘발성 아이템 보존은 기존 지역 이동 경로를 사용한다.

## 제작 이미지

이미지는 기본 내장 imagegen으로 제작했다. 콘덴서 아이콘은 투명 배경의 짙은 청록색 산업용 원통 콘덴서, 은색 단자 두 개, 노란 번개 표식이라는 프롬프트로 생성했다. 목적지 카드는 각각 숲길, 동쪽 마을과 급수탑, 서쪽 마을과 풍차, 초원이라는 가로형 게임 배경 일러스트 프롬프트를 사용했다. 카드 이미지의 건물은 목적지 안내용 일러스트이며 실제 맵 배치를 뜻하지 않는다.

## 배치용 에셋

- 리프트 BP: `/Game/Interaction/RaidLift/BP_RaidLift`
- 시작 지점 BP: `/Game/Interaction/RaidLift/BP_RaidPlayerStart`
- 기지 배치: `BunkerMap`의 `Base_RaidLift`, 위치 `(-600, -200, 6.244)`, 균일 배율 `0.75`. 발판 180cm, 레일 높이 375cm.
- 숲 3개, 마을 동쪽 3개·서쪽 3개, 평원 3개의 시작 지점을 배치한다. 기존 일반 시작 지점과 숲의 별도 통로 리프트는 유지한다.

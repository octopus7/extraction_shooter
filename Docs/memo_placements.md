# 메모 임시 배치

메모 ID 1~60을 예약하고 아래 본편 맵에 전용 `/Game/Interaction/BP_MemoAnchor`를 직접 배치했다.

| 지역 | 맵 | MemoId | 개수 |
| --- | --- | --- | --- |
| 숲 | `/Game/MainRaid/RaidForest` | 1~15 | 15 |
| 마을 | `/Game/MainRaid/RaidVillage` | 16~50 | 35 |
| 평원 | `/Game/MainRaid/RaidPlains` | 51~60 | 10 |

## 찾아서 옮기기

- 월드 아웃라이너의 `Memos` 폴더를 펼치거나 `Memo_`로 검색한다.
- 액터 이름은 `Memo_001`~`Memo_060`이다. 원하는 액터를 선택하고 뷰포트에서 `F`로 초점을 맞춘 뒤 이동한다.
- 각 액터의 **MemoId**가 수집 기록의 ID다. 같은 메모를 옮길 때에는 ID를 유지한다. 라벨의 0 채움은 검색 편의를 위한 표시 형식이다.
- 메시와 재질은 전용 BP의 로우폴리 저장 장치 기본값을 사용한다.
- 위치와 회전은 맵에 저장되어 있으며 실행할 때 다시 무작위 배치하지 않는다. 자동 재생성 코드도 남겨 두지 않는다.

이번 임시 배치는 맵 내부의 지형 표면에서 무작위 지점을 선택했다. 메모 간 최소 간격은 15m이며, 경사 약 23도 이상과 수직 방향 장애물·플레이어가 설 공간이 막힌 지점을 제외했다. 이는 임시 배치 조건으로, 모든 지점까지의 실제 플레이 이동 경로를 보장하는 검증은 아니다.

## 임시 내용

`MemoDefinitions.json`에 1~60번의 `memo_id`와 `body_string_key`만 정의한다. 개별 제목은 없으며, 공통 `memo.title_format`과 최소 세 자리 0 채움 번호로 `메모 001`, `메모 010`, `메모 060`처럼 표시한다. 1000 이상은 자르지 않는다. 목록과 상세 제목에 같은 형식을 사용하고, 미획득 목록도 번호를 표시하되 본문 열기는 비활성 상태를 유지한다.

본문은 `memo.N.body` 키를 사용한다. 최초 예약 시 한국어 본문을 `메모 N 번`으로 채웠으며, 기존 1~20번의 내용도 임시 문구로 교체했다. 이후 작성된 본문은 해당 키의 실제 내용으로 대체한다.

10번 본문은 `작은 녀석이 뿜는 가스는 매우 강하다`이다. 각 언어에서도 가스로 은유하며 방귀를 직접 지칭하지 않는다.

11번 본문은 `강력한 폭발이 필요하다`이다. 숲에서 마을로 가는 통로의 장애물을 폭파로 철거해야 한다는 힌트다.

`MemoTextStrings.csv`와 `Translations/MemoTextStrings.csv`에 공통 제목 형식 1개와 본문 60개, 총 61개 키와 7개 언어 번역을 둔다. 나중에 내용을 작성할 때는 기존 ID와 본문 키를 유지하고 문구만 바꾼다. 배치 변경으로 이미 저장된 수집 기록이 초기화되지는 않는다.

읽기 전용 검증 도구는 `Tools/MemoAnchors/verify_placements.py`이다. 일반 Python의 `--data-only` 옵션은 ID·문자열을 확인하며, Unreal Python 명령행 실행은 맵의 배치 개수·ID·BP·메시·아웃라이너 이름을 확인한다. 좌표를 고정값과 비교하거나 다시 배치하지 않는다.

# 일시정지 메뉴

- 일반 플레이에서 ESC로 연다. 기존 HUD 패널 또는 하우징 작업이 열려 있으면 먼저 닫거나 취소한다.
- 에디터 PIE에서는 ESC의 에디터 종료 동작을 변경하지 않는다. `/Game/Input/IMC_Player`에 K가 미할당인 경우 K를 같은 메뉴 입력으로 추가한다. 패키지에는 K 단축키를 추가하지 않는다.
- 메뉴를 연 동안 실제 월드를 정지하고 플레이어 행동 입력을 차단한다. 계속하기 또는 메뉴에서 ESC/K로 복귀한다.
- 설정은 기존 설정 화면을 재사용한다. 해상도 확인, 설정 화면, 종료 확인 팝업 순으로 닫기를 처리하며 메뉴로 돌아와도 월드는 계속 정지한다.
- 타이틀로/게임 종료를 선택하면 확인 팝업을 먼저 띄운다. 확인 전에는 저장·아이템 손실·레벨 이동·종료가 발생하지 않는다.
- 진행 상황 손실 경고는 레이드에서만 표시한다. 벙커에서는 타이틀 이동 또는 종료 여부만 묻고, 별도 안내문과 그 여백은 표시하지 않는다.
- 벙커에서는 확인 시 변경 여부와 관계없이 현재 상태를 저장하고, 저장 성공 후 타이틀로 이동하거나 종료한다. 레이드 중단은 소지품·장비·퀵슬롯·이번 레이드 경험치를 잃는 기존 사망 손실 규칙을 적용하고, 창고와 퀘스트/월드 진행은 보존한다. 탈출 성공 보상은 적용하지 않는다.
- 저장 실패 시 메뉴에 오류를 표시하고 종료를 중단한다. 레이드의 메모리 상태도 복원해 취소 후 플레이를 계속할 수 있다.
- 타이틀, 최초 오프닝, 대화/엔딩 연출, 사망 상태에서는 일반 일시정지 메뉴를 열지 않는다.
- 모든 신규 표시 문구는 `Content/Data/UITextStrings.csv`의 `ui.pause.*` 또는 기존 공통/설정 키를 사용한다. 한국어·영어·일본어를 함께 제공하며 코드의 표시용 대체 문구는 사용하지 않는다.

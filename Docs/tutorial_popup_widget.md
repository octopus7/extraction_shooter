# 설명용 팝업 초벌

## 에셋과 편집

- `/Game/UI/Tutorial/WBP_TutorialPopup`: UMG 디자이너에서 계층을 직접 편집하는 설명용 팝업.
- `CommonFrame`: 모든 페이지가 공유하는 종이 질감 프레임.
- `PageSwitcher`: Active Widget Index를 0/1/2로 바꾸어 기본 조작, 전투, 아이템 페이지를 편집.
- 각 페이지의 `Illustration`, `Heading`, `Description` 위젯에서 이미지, 배치, 크기, 글꼴, 색상을 수정.
- `PopupSize`: 기준 크기 1440×960. 바깥 `PopupScale`이 화면 크기에 맞게 비율을 유지.
- `ContinueButton`: 실제 첫 도움말을 열 때 컨트롤러가 닫기 이벤트를 연결한다. 디자이너 미리보기에서는 연결하지 않는다.
- `F_TutorialText` 및 `FF_Tutorial*`: 기존 프로젝트 글꼴과 CJK 대체 글꼴의 데이터를 포함하는 폰트 에셋.

## 로컬라이징

표시 문구는 `TunaSweeper/Content/Data/UITextStrings.csv`의 `ui.tutorial.*`와 기존 `ui.common.continue` 키를 사용한다. WBP Class Defaults의 `LocalizedTextKeys`는 디자이너 위젯 이름과 문자열 키를 연결한다. 텍스트 변경은 CSV에서, 배치와 스타일 변경은 디자이너에서 한다.

Class Defaults의 `PreviewLanguage`로 게임 인스턴스가 없는 디자이너에서 한국어·영어·일본어를 확인한다. 최소 네이티브 기반 클래스는 저장된 TextBlock의 내용만 갱신하며 위젯을 생성하거나 레이아웃을 덮어쓰지 않는다. 실제 게임 인스턴스가 있으면 기존 게임 언어 설정을 읽는다.

## 현재 범위

`BunkerMap`에서 플레이어가 `(-439.010357, -135.576503, 79.345408)` 주변에 처음 진입하면 기본 조작 페이지(인덱스 0)를 표시한다. 컨트롤러 Class Defaults의 Tutorial 항목에서 `BasicsTutorialCenter`와 `BasicsTutorialExtent`를 조정한다. 기본 영역은 중심으로부터 X/Y ±70cm, Z ±100cm다. 맵 에셋을 재생성하거나 런타임에 위젯 계층을 만들지 않는다.

게임을 일시 정지하고 게임 입력과 뒤쪽 HUD를 차단한다. ‘계속’을 클릭하거나 포커스된 버튼을 키보드로 실행하면 닫고 재개한다. 대화·하우징·다른 메뉴·기존 입력 잠금 및 레벨 전환 연출 중에는 조작 가능해질 때까지 기다린다.

두 번째 전투 페이지(인덱스 1)는 벙커에서 실제 레이드로 출발한 뒤 레벨 전환 연출이 끝나고 이동/시점 입력이 복구되면 표시한다. 레이드 맵을 직접 여는 경우에는 예약하지 않는다. 확인 시 `tutorial.raid.combat_seen`을 같은 저장 슬롯에 기록하므로 재출격/불러오기에서는 다시 표시하지 않고 새 게임/슬롯 초기화 시에만 다시 표시한다. 진입 대기 상태는 임시 상태이며 로드/슬롯 초기화에서 지운다. 세 번째 아이템 페이지는 자동으로 열지 않으며 아래 다시 보기에서만 접근한다.

## 응접실에서 전체 다시 보기

`BunkerMap` 중앙 티테이블 `(11.856562, 60.546406, 70)`에 `TutorialControls_Review` 액터를 저장했다. 클래스는 `ATunaSweeperTutorialReviewActor`이며 게임에서 메시가 보이지 않고 충돌하지 않는다. 기존 상호작용 마커/키는 유지하고 `ui.interaction.tutorial_review`를 한국어 ‘조작법’, 영어 ‘Controls’, 일본어 ‘操作方法’으로 표시한다.

상호작용하면 게임을 일시 정지하고 첫 페이지부터 전체 다시 보기를 연다. `PreviousPageButton`/`NextPageButton`은 WBP에 저장된 그림 아이콘이며 이 모드에서만 보인다. 좌우로 3페이지를 순환하며 첫 페이지에서 왼쪽은 마지막, 마지막에서 오른쪽은 첫 페이지로 이동한다. ‘계속’으로 닫고 게임을 재개한다. 언제든 반복해서 열 수 있으며 자동 도움말의 완료 플래그나 저장 데이터를 변경하지 않는다.

확인 시 기존 저장 슬롯의 `CompletedScenarioFlags`에 `tutorial.bunker.basics_seen`을 추가하고 즉시 저장을 시도한다. 같은 세션 및 저장한 슬롯에서는 재표시하지 않으며 새 게임/슬롯 초기화 시 다시 표시한다. 저장 실패 시 메모리의 확인 기록은 유지하며 다음 정상 저장에 포함된다. 저장이 끝나기 전에 강제 종료한 경우에는 다시 표시될 수 있다. 기본 키 매핑 안내는 유지하며 키 재매핑 표시는 별도 작업이다.

## 생성·검증

에디터 전용 생성기로 한 번 만든 일반 WBP 에셋이다. 생성기는 제거되어 있으며 최종 소스에는 자동 재생성 경로가 없다. 향후 일회성 생성 작업도 에셋 검증 및 생성기 제거·재검증 후 한 작업 커밋으로 정리한다.

`TunaSweeper.UI.Tutorial.AuthoredAsset` 검사는 새 프로세스에서 저장된 디자이너 트리, 3페이지, 25개 문자열 키, 언어별 텍스트, 비연결 버튼, UI 텍스처 설정을 확인하고 실제 UMG를 렌더링한다. 미리보기는 `GeneratedImages/UI/Tutorial/WidgetPreviews/`에 저장된다.

`TunaSweeper.UI.Tutorial.FirstPassage`는 첫 페이지 위치/높이 조건과 두 번째 페이지 벙커 출발/연출 종료 조건, 대화/입력 잠금, 실제 WBP 표시, 일시 정지, 중복 팝업 방지, 계속 버튼, 입력 복원 및 두 완료 플래그의 저장 직렬화·슬롯 초기화를 검사한다. 실제 사용자 저장에는 접근하지 않는다.

동일 검사에 투명 액터의 실제 상호작용, 양쪽 끝 순환, 세 번째 페이지 접근, 재열기 및 자동 완료 플래그 불변 검증을 포함한다. 에셋 검사는 저장된 응접실 액터가 정확히 하나인지 확인하고 `Tutorial_Review_Items_ko.png`로 화살표가 보이는 세 번째 페이지를 렌더링한다.

# 본편 레이드 맵 크기와 임시 배치

2026-10-12 재구성 기준. 과거 제작 문서의 504m 지형과 500m 내부 경계 대신 아래 크기를 사용한다. 월드 단위는 cm이며 북쪽은 +X다.

| 맵 | 지형 크기 | 이동 경계 내면 | 지형 축소 비율 |
| --- | --- | --- | --- |
| `/Game/MainRaid/RaidForest` | 200×200m | X/Y ±10000cm | 200/504 |
| `/Game/MainRaid/RaidVillage` | 300×300m | X/Y ±15000cm | 300/504 |
| `/Game/MainRaid/RaidPlains` | 200×200m | X/Y ±10000cm | 200/504 |

기존 Landscape의 64개 컴포넌트와 페인트 레이어를 유지하고 XYZ를 같은 비율로 조정해 경사를 보존한다. 일반 건물·소품·차량은 원래 크기를 유지한다. 경계는 두께 10m의 BlockingVolume 네 개이며 모서리가 겹치도록 배치한다.

## 마을 중앙 테스트 배치

철도·역·열차는 연결을 유지하며 300m 지형에 맞춰 배치를 조정한다. 나머지 테스트용 건물·소품·메모·상호작용 액터는 원점 중심 50×50m 안에 모은다. Landscape, 월드 조명, 경계와 리뷰 카메라는 중앙 집중 대상에서 제외한다.

중앙 배치는 원래 XY 좌표의 비례 압축을 기본으로 한다. 조립된 건물 부품과 짝을 이루는 상호작용 액터는 관계를 보존하며, 접근을 막는 겹침은 국소적으로 조정한다. 에디터 구획 미리보기 데칼도 중앙 영역에 맞춰 작게 조정한다.

## 마을 외곽 철도

철도 중심선은 X ±120m, Y ±110m 범위의 둥근 사각형 폐회로다. 160m 직선 두 개와 140m 직선 두 개를 반경 약 40m의 곡선으로 연결한다. 맵 내부 경계까지 최소 30m 여유를 두며, 세 역은 각각 직선 위에 배치한다. 승강장 길이 38m와 열차 4량의 크기는 유지한다.

역 구간은 편성 전체가 수평·직선 상태로 정차할 수 있도록 한다. 철로와 승강장 아래의 좁은 지형 통로만 높이를 맞추며, 중앙 50×50m 테스트 배치는 유지한다. 자세한 스플라인 좌표·접선·정차 거리와 변경 전 맵 백업 정보는 `Docs/level_layout_snapshots/`의 철도 배치 기록을 따른다.

## 원래 좌표 복원

`Docs/level_layout_snapshots/`의 맵별 JSON은 이번 변경 직전과 변경 후의 액터 변환을 보관한다. 액터의 안정적인 이름과 경로로 대조하고 원본 location/rotation/scale을 적용하면 원래 배치를 복원할 수 있다. 액터 이름, 메모 ID, 퀘스트·이동 참조는 유지한다.

단순한 일괄 배율 변경만으로는 지면 높이 보정이나 연결된 액터 묶음의 예외까지 정확히 복원할 수 없다. 정확한 원형 복원에는 JSON의 원본 변환을 사용한다. 철도 스플라인·역 거리·데칼 등 별도 속성이 변경된 경우도 같은 기록의 원본값을 함께 적용한다. 이 기록은 편집용 자료이며 런타임 생성이나 세이브 데이터로 사용하지 않는다.

외곽 철도 재구성 시 수정한 Landscape 높이 데이터는 액터 변환 JSON에 포함되지 않는다. 지형까지 이전 상태로 되돌리려면 변경 전 맵 백업 또는 해당 Git 리비전의 맵 패키지를 사용한다.

Landscape 배율을 편집 스크립트에서 변경할 때는 충돌을 재생성하고 저장한 맵을 다시 열어 지면을 확인한다. 단순 액터 scale setter 직후의 지면 검사만으로 높이를 확정하지 않는다. 소수 격자 간격의 정확한 꼭짓점에서 수직 ray가 빗나갈 수 있어 검증기는 1.5mm 이내의 인접 ray를 보조로 사용하며, 실제 플레이어 크기의 캡슐 충돌 검사는 원래 좌표에서 수행한다.

## 검증

`Tools/MainRaidLevels/run_verify.ps1`은 저장된 세 맵을 새 에디터 프로세스에서 열어 실제 지형 크기, 시작점 캡슐 공간, 주요 이동 경로, 경계 충돌과 철도 연결을 검사한다. `Tools/MainRaidLevels/run_capture.ps1`은 맵별 리뷰 카메라 이미지를 저장한다. 결과는 `TunaSweeper/Saved/MainRaidLevels/`에 기록된다.

`Tools/LoopRailLayout/`은 마을 철도의 직선 정차·지면 간격·경사·주행을 검사하고, 전체 노선과 세 역의 정차 모습을 읽기 전용으로 캡처한다. 결과는 `TunaSweeper/Saved/LoopRailLayout/`에 저장한다.

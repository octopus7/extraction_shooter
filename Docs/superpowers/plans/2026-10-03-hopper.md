> For agentic workers: implement the defined independent asset and gait tasks, then integrate and verify the complete feature in the current chat.

**Goal:** A playable three-phase Hopper enemy with a seated rabbit, modular arms and heavy IK locomotion.
**Architecture:** Existing enemy base plus Hopper phase/presentation and interchangeable arm actors. Independent pure gait solver and authored pilot animations.
**Tech Stack:** Unreal Engine 5.7 C++, Blender 4.5, FBX and Unreal assets.
**Spec:** ../specs/2026-10-03-hopper-design.md

## Global constraints
- Existing localization workflow for UI text; UE centimeters, +X forward, +Z up.
- Preserve original model source and current main checkout changes.
- One task commit includes final assets, implementation, cleanup, validation and request log.

## Review focus
- Lethal mech hit must not kill the pilot or award duplicate kills.
- A blocked dismount must not place the rabbit inside geometry.
- Empty ammunition includes reserve/reload behavior and cannot shoot infinitely.
- Missing/replaced arm modules cannot leave orphan actors or stale fire state.
- Ground misses, teleports, frame hitches and sharp turns must not produce invalid IK poses.

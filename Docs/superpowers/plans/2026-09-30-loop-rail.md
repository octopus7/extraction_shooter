# Loop Rail Implementation Plan

> Execution: implement inline, using the user's approved train scope; include implementation, temporary asset-builder removal, validation and task log in one commit.

**Goal:** A reusable UE 5.7 plugin providing a looping electric train, editable rail spline, stations and level crossings.

**Architecture:** LoopRail runtime actors share a spline-distance model. Saved replaceable static meshes supply the blocking art and simple collision. Stations reference tracks and mark the locomotive centre's stop position. Crossings follow the whole consist, including the rear carriage. Native CharacterMovement moving bases carry standing passengers; seats are scenery.

**Tech Stack:** UE 5.7 C++, static meshes, Unreal automation; standalone C++ tests for distance/motion rules.

**Spec:** User instructions in this chat: separate plugin; one simple chimney on locomotive; 8 rows of 1+1 seats per carriage; default 4 vehicles including locomotive, configurable; fewer than 500 faces per vehicle; replaceable blocking art at correct scale; walk-on riding, no sitting interaction.

## Global Constraints

- centimetres, +X vehicle forward, +Z up; locomotive and carriage 900cm long, 220cm wide; carriage aisle 90cm, floor top 60cm.
- triangulated mesh budget <500 per vehicle; sixteen seats per passenger carriage.
- no runtime user-facing text added. No dependency on the game's main module.
- raid entry resets train position; no new saved gameplay state.
- preserve all unrelated pre-existing changes. Work on codex/loop-rail-plugin using the existing project's build products.
- no completed one-off asset generator or startup regeneration in final source.

## Review Focus

- negative distances and wrapping across the route seam.
- braking and stop arrival at large frame deltas; departure must not retrigger the same stop.
- crossings remain closed until the entire train clears, including route seam and stopped trains.
- floor collision is a moving base; aisle and entrances clear the 68cm player capsule.
- invalid/missing/open/too-short track fails safely; changed vehicle count rebuilds without stale components.

# 평원 중앙 SSTO 착륙선

## 사용자 요구

- 제작한 총과 비슷한 두툼한 형태·모따기·정돈된 패널을 사용한다. 총의 민트·보라색 배색은 반복하지 않는다.
- 3번 평원맵 `/Game/MainRaid/RaidPlains` 중앙에 비스듬히 착륙한 SSTO를 배치한다.
- 사다리를 갖추고 내부 화물실과 조종석을 걸어 다닐 수 있게 한다.
- 사다리는 사용자 선택에 따라 상호작용으로 내부/외부 출입 위치를 오간다.
- 상부가 경계 디졸브로 사라지는 기존 시야 구현을 적용한다.

## 형태와 공간

약 26m 길이, 18m 날개폭의 유인 우주비행기로 제작한다. 주황색 외장, 짙은 청회색 구조체, 밝은 회색 보조 패널을 사용한다. 앞쪽 조종석, 뒤쪽 화물실, 좌측 사다리, 후방 엔진 두 기와 꼬리날개를 갖춘다. 중앙 통로는 최소 180cm, 내부 유효 높이는 최소 260cm를 확보한다.

바닥과 낮은 동체, 내부 가구, 날개와 하부 장치를 상부 외장·지붕·캐노피와 별도 메시로 만든다. 같은 맵에서 실내를 탐색하며, 기체의 작은 피치/롤과 대각선 방향 배치는 플레이 가능한 바닥 경사를 유지한다. 실제 지형 높이를 확인해 착륙 장치와 사다리 지면 접점을 맞춘다.

## 동작

- 짝지어진 사다리 출입 액터의 도착 지점은 바닥 위치다. 이동 시 현재 플레이어 캡슐 높이를 적용한다.
- 같은 월드의 유효한 짝과 안전한 도착 공간이 있어야 이동한다. 막힌 출구·잘못된 참조는 현재 위치를 유지한다.
- 기존 상호작용 시스템과 문자열 키를 사용하며 출입 문구를 로컬라이즈한다.
- `UTunaSweeperVerticalOcclusionRevealComponent`의 기존 높이 경계와 디졸브 파라미터를 사용한다. 새 옵션은 원본 호환 재질을 유지하며 기본 동작을 바꾸지 않는다.
- 저장되는 진행 상태는 추가하지 않는다.

## 파일 및 검증 범위

모델 원본 산출물은 `TunaSweeper/SourceArt/Environment/SSTO_Lander`, UE 패키지는 `/Game/MainRaid/SSTO`에 둔다. 새 사다리 런타임 클래스, 상호작용 연결, 재질 보존 옵션을 검사한다. GLB/FBX 및 저장된 UE 패키지를 재로드하고, 출입 왕복·막힌 도착지·캡슐 여유·실내 바닥·기체 시야 디졸브를 검증한다. 기존 평원맵 작업을 보존한다. 임시 생성기 제거 후 재검증하고 구현·산출물·작업 기록을 한 커밋에 포함한다.

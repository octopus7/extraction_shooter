# 해안 갈매기와 해변 배치

## 활동 범위

플레이어와 갈매기 사이의 월드 거리가 100m 이내라면 화면 밖에서도 움직인다. 화면 경계로 활성 여부를 결정하는 방식도 검토했고 사용자가 거리 기준을 선택했다. 갈매기별 상시 Tick 대신 공유 거리 검사로 깨우고, 동면 중에는 개별 이동·상태 전환·애니메이션 갱신을 중단한다. 다시 접근하면 현재 위치에서 이어간다.

## 모션과 배치

흰 몸과 회색 날개, 검은 날개 끝이 보이는 갈매기를 재사용 가능한 BP로 만든다. 땅에서는 날개를 접고 좌우 발을 번갈아 디디며 걷는다. 이륙할 때 몸을 밀어 올리며 날개를 펴고, 비행 중에는 날갯짓과 활공을 섞는다. 착지할 때 발을 내리고 감속한 뒤 날개를 접는다. 물 위는 비행 경로로 사용하고 이착륙 지점은 마른 지면에 둔다.

RaidVillage의 해병고양이·해적고양이 기지 쪽 해변, RaidForest에서 물길이 넓어지는 EastFan·RiverMouth 주변에 갈매기를 배치한다. 야자수는 두 기지 쪽 해변 뒤편 녹지와 모래 경계에 작은 무리로 심고 모래 위에는 조개껍데기와 유목을 모델링해 흩어 놓는다. 개체 수·높이·간격은 지면 경사와 실제 플레이 카메라를 보고 정한다. 이동 동선과 기지 입구를 비워 둔다.

## 검증과 납품

UE 5.7에서 두 맵의 배치와 지면 접촉, 걷기·이륙·비행·착지, 거리 경계 왕복, 화면 밖 근거리 이동을 확인한다. 기존 숲 맵의 미커밋 변경은 분리하고, 에셋·동작·작업 기록을 검증한 뒤 이번 변경만 한 번에 커밋한다.

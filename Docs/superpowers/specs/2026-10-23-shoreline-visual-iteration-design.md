# 해안 물 표현 반복 개선

요청 시작: 2026-10-23 17:41:57.

사용자는 최근 ShorelineReference 작업을 이어서 스스로 표현력을 반복 개선하고, 분석용 스크린샷을 계속 보존하도록 요청했다. 모든 커밋은 사용자의 추후 명시적 요청까지 보류한다.

## 방향

기존 잔잔한 해안 거품을 유지하면서 평평한 수면에 깊이감과 움직임을 더한다. 작은 반짝임을 가득 채우기보다는 넓은 잔물결 반사와 얕은 바닥 빛무늬를 우선한다. 원본 화면, 첫 구현, 조정 결과를 같은 카메라·고정 시각으로 직접 비교한다.

선택은 에이전트 판단이다. 색/기존 파라미터만 조정하면 표면의 방향성 변화가 부족하고, 엔진 Water/SingleLayerWater로 전환하면 기존 독립 재질의 범위를 크게 바꾼다. 현재 반투명 재질에 조절 가능한 표면 레이어를 추가하는 방식을 선택한다. 기존 프로젝트/게임플레이 물은 그대로 둔다.

## 범위와 보존

- UE 5.7 D3D12/SM6 실제 렌더로 비교한다. 수면 높이와 충돌은 변경하지 않는다.
- 대상은 `TunaSweeper/Plugins/ShorelineReference`의 물 재질·소스·검토 도구와 독립 검토 맵의 수면 범위다.
- 수면 잔물결, 시선 방향에 따른 넓은 하늘색 반사, 절제된 햇빛, 얕은 물의 카스틱을 순서대로 비교한다. 물리적인 반사/굴절 완성으로 표현하지 않는다.
- 스크린샷은 `Resources/Iterations/<실행시각-단계>/<뷰>/yyyymmdd-hhmm.png`에 저장한다. 같은 분의 다른 뷰는 하위 폴더로 구별하고 덮어쓰지 않는다. 원본 렌더 픽셀을 보존하며 색·해상도·필터 후처리를 하지 않는다. PNG 컨테이너의 IEND 뒤 여분 바이트만 정리하고 원래 해시를 기록한다.
- 각 실행 manifest에 카메라, 셰이더 시각, 소스 해시, 파라미터와 파일 경로를 기록한다.
- 에디터 자산 갱신용 일회성 스크립트는 최종 검증 후 삭제한다. 읽기 전용 비교/검증 도구는 유지한다.
- 커밋·스테이징을 하지 않는다. 기존 미커밋 질문 기록도 보존한다.

## 평가

보기 좋은지는 실제 이미지로 판단한다. 자동 검사는 레이어 끄기/켜기 차이, 고정 시각 재현, 해안 범위, 정상 셰이더, 저장 자산/소스 일치와 의존성 격리를 확인한다. 기존 거품 마스크 회귀 검사는 유지한다. 카메라 이동과 시간 변화도 최종 영상에서 확인한다.

# 맵 및 세션 동선 설계

## 기본 맵 형태

대문자 L자 구조.

- 짧은 가로 방향: 취수 시설
- 긴 세로 방향: 북쪽 파밍 지역
- 긴 방향 끝: 익스트랙션 포인트
- 시작점: 벙커

## 거리 기준

- 벙커 → 취수 시설
  - 단순 이동: 약 40초
  - 교전 포함: 약 1분

- 취수 시설 왕복
  - 약 2분~2분 30초

- 세션 전체
  - 약 3분 전후

## 일반 플레이 흐름

### 첫 외출
- 벙커 출발
- 취수 시설까지 교전 2회
- 막힌 스크린 조사
- 도구 필요 확인
- 귀환

### 두 번째 외출
- 크로우바 획득
- 취수 시설 이동
- 교전 2회
- 스크린 청소
- 밸브 손잡이 파손 확인
- 귀환

### 세 번째 외출
- 북쪽 파밍 지역 이동
- 수리 부품 획득
- 필요 시 취수 시설 방문
- 벙커 수리
- 최종 퀘스트 진행

## 교전 반복 방지

같은 길을 여러 번 지나더라도 적 배치를 바꾼다.

- 첫 방문: 정면 위주의 기본 교전
- 두 번째 방문: 측면 등장 또는 다른 엄폐 사용
- 세 번째 방문: 기존 전투 흔적 유지, 다른 사격각

적 숫자를 계속 늘리기보다 다음 요소를 변경한다.

- 스폰 위치
- 플레이어 발견 시점
- 엄폐 위치
- 접근 방향
- 사격 거리

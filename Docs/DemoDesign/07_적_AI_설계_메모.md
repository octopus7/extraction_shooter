# 적 AI 설계 메모

## 현재 방향

적이 플레이어에게 무조건 달라붙는 방식은 피한다.

적은 어느 정도 거리를 좁히지만, 적정 거리에서 사격과 이동을 반복한다.

## 기본 행동 루프

```text
플레이어 발견
→ 짧은 인지 반응
→ 조준
→ 점사
→ 좌우 이동 또는 엄폐
→ 필요하면 접근
→ 다시 사격
```

## 필요한 행동

- 발견 전 인지 지연
- 발견 즉시 완벽한 명중 사격 금지
- 적정 거리까지 접근
- 일정 거리에서 정지하고 점사
- 측면 이동
- 피격 시 잠깐 후퇴
- 엄폐 탐색
- 너무 가까우면 거리 벌리기
- 같은 자리에서 계속 사격하지 않기

## 교전 밸런스

### 첫 교전
- 적 1~2명
- 초보 플레이어가 한두 발 맞을 가능성
- 첫 탄에 바로 사망하지 않음
- 엄폐와 이동을 자연스럽게 학습

### 두 번째 교전
- 더 복잡한 사격각
- 회복하지 않거나 방심하면 위험
- 단순 숫자 증가보다 측면 압박

## 명중률

로봇처럼 정확한 사격은 피한다.

- 기본 스프레드 부여
- 첫 발 명중률 낮춤
- 연속 사격 시 압박은 증가
- 가까워질수록 위협 증가

# 아이템 및 기능성 프랍

## 필수 퀘스트 아이템

### 크로우바
- 용도: 취수 스크린의 수초와 이물질 제거
- 위치: 벙커 내부 공구 보관 장소
- 필요 리소스:
  - 아이콘
  - 월드 메시
  - 획득 연출
  - 스크린 청소 애니메이션 또는 인터랙션

### 교체용 밸브 손잡이
- 용도: 취수 시설 밸브 수리
- 획득: 외부 적 드랍 또는 파밍
- 필요 리소스:
  - 아이콘
  - 월드 메시
  - 설치 전/후 메시 상태
  - 밸브 회전 연출

### 방수 테이프
- 용도: 벙커 내부 누수 배관 수리
- 획득: 외부 적 드랍 또는 파밍
- 필요 리소스:
  - 아이콘
  - 월드 메시
  - 배관 수리 전/후 상태

### 참치캔
- 용도: 최종 보상 및 엔딩
- 위치: 외부 식량 창고
- 필요 리소스:
  - 아이콘
  - 월드 메시
  - 전달 이벤트

## 최소 일반 루팅 아이템

- 탄약
- 회복 아이템
- 스크랩 또는 잡동사니 1종

완전한 경제 시스템은 데모 단계에서 필수는 아니다.

## 기능성 프랍

### 벙커 내부
- 화장실
- 물 내리는 버튼
- 경고등
- 경고 스피커
- 캔봇
- 공구 보관대
- 누수 배관
- 식량 또는 아이템 보관 구역

### 취수 시설
- 원통형 취수 스크린
- 걸린 수초와 나뭇가지
- 크로우바 청소 지점
- 밸브 본체
- 파손 손잡이
- 교체 손잡이
- 물 흐름 전/후 효과
- 수리 전/후 상태

### 외부
- 식량 창고
- 참치캔 배치 지점
- 파밍 상자
- 익스트랙션 포인트

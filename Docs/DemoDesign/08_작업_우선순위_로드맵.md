# 작업 우선순위 로드맵

- 플레이어 1명
- 적 2명
- 엄폐물
- 발사 피드백
- 적 피격
- 적 사망
- 플레이어 피격
- 환경 피격
- 기본 사운드

완료 기준:

> 퀘스트와 보상이 없어도 반복 플레이하고 싶은 수준

## 2순위: AI 리듬 조정

- 거리 유지
- 점사
- 측면 이동
- 피격 후 후퇴
- 엄폐
- 접근/이탈 판단

- 실제 이동 속도로 직접 걸어보기
- 교전 포함 편도 시간 측정
- 취수 시설 왕복 시간 측정
- 세션 3분 내외 확인

- 적 배치 변화
- 다른 사격각
- 진행 목적 변화
- 전투 흔적 유지

## 5순위: 퀘스트 상태 구현

- 손잡이 설치

- 참치캔

- 크로우바

- 퀘스트 아이템 분실

- 중복 드랍 방지

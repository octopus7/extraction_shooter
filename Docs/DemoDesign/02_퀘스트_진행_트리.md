# 퀘스트 진행 트리

## 전체 흐름

```text
프롤로그: 화장실 고장
    ↓
Q1. 취수 시설 확인
    ↓
Q2. 크로우바 획득 및 스크린 청소
    ↓
레버 손잡이 파손 + 벙커 배관 누수 확인
    ↓
Q3-1. 밸브 손잡이 확보 및 취수 시설 수리
Q3-2. 방수 테이프 확보 및 벙커 배관 수리
    ↓
두 퀘스트 모두 완료
    ↓
Q4. 외부 식량 창고에서 참치캔 획득
    ↓
엔딩: 화장실 정상 작동 확인
```

## Q1. 취수 시설 확인

### 시작 조건
- 게임 시작
- 주인공이 화장실 사용
- 물이 내려가지 않음
- 급수 경고 발생
- 캔봇과 대화

### 목표
- 외부 취수 시설에 도착
- 취수 스크린 조사

### 완료 조건
- 막힌 스크린 인터랙션

### 결과
- 수초와 이물질이 걸려 있음
- 맨손으로 제거 불가능
- 크로우바 필요
- 벙커 귀환 목표 생성

---

## Q2. 막힌 스크린

### 시작 조건
- Q1 완료
- 벙커에서 캔봇과 대화

### 목표
1. 공구 보관 장소에서 크로우바 획득
2. 취수 시설로 이동
3. 크로우바로 스크린 이물질 제거

### 완료 조건
- 청소 인터랙션 완료

### 결과
- 물은 다시 들어오기 시작함
- 밸브 또는 레버 손잡이가 파손되어 있음을 발견
- 벙커 내부 배관 누수 문제도 발생

---

## Q3-1. 부러진 밸브 손잡이

### 시작 조건
- Q2 완료

### 목표
1. 외부 적 또는 파밍 구역에서 교체용 손잡이 획득
2. 취수 시설에 설치
3. 밸브 조작

### 완료 조건
- 취수 시설 정상 작동

---

## Q3-2. 새는 벙커 배관

### 시작 조건
- Q2 완료

### 목표
1. 외부에서 방수 테이프 획득
2. 벙커 내부 손상 배관에 사용

### 완료 조건
- 누수 정지
- 벙커 급수 압력 정상화

---

## Q4. 오늘의 보상

### 시작 조건
- Q3-1과 Q3-2 모두 완료

### 목표
- 외부 식량 창고에서 참치캔 획득
- 벙커로 귀환

### 완료 조건
- 참치캔 전달
- 화장실 정상 작동 확인

### 엔딩
- 물 내려가는 소리
- 주인공의 안도
- 데모 감사 메시지

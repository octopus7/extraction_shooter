# 플레이테스트 체크리스트

## 진행 테스트

- [ ] 화장실 사용 후 경고가 정상 발생한다.
- [ ] 두더지와 첫 대화 후 퀘스트가 시작된다.
- [ ] 취수 시설 조사로 Q1이 완료된다.
- [ ] 크로우바 없이 청소할 수 없다.
- [ ] 크로우바 획득 후 스크린 청소가 가능하다.
- [ ] 스크린 청소 후 밸브 손잡이 파손이 드러난다.
- [ ] Q3-1과 Q3-2가 동시에 열린다.
- [ ] 두 퀘스트를 모두 끝내야 Q4가 열린다.
- [ ] 참치캔 획득 후 엔딩이 진행된다.
- [ ] 화장실 물 내려가는 소리가 정상 출력된다.

## 예외 테스트

- [ ] 인벤토리가 가득 찬 상태
- [ ] 퀘스트 아이템을 놓친 상태
- [ ] 퀘스트 아이템을 버리려는 경우
- [ ] 적 드랍 아이템이 사라진 경우
- [ ] 교전 중 사망
- [ ] 손잡이나 테이프를 먼저 획득한 경우
- [ ] 북쪽 지역을 먼저 방문한 경우
- [ ] 익스트랙션을 먼저 사용한 경우
- [ ] 걸어서 벙커에 귀환한 경우
- [ ] 엔딩 이후 조작 가능 여부

## 시간 테스트

- [ ] 벙커 → 취수 시설 단순 이동 약 40초
- [ ] 교전 포함 편도 약 1분
- [ ] 첫 왕복 약 2분~2분 30초
- [ ] 한 세션 약 3분
- [ ] 전체 데모 약 10~15분

## 전투 테스트

- [ ] 첫 발에 억울하게 죽지 않는다.
- [ ] 적 두 명과 싸우면 긴장감이 있다.
- [ ] 총을 맞힌 사실이 즉시 느껴진다.
- [ ] 플레이어 피격 방향이 읽힌다.
- [ ] 적 사망이 명확하다.
- [ ] 흙, 바위, 상자, 물 피격이 구분된다.
- [ ] AI가 계속 달라붙지 않는다.
- [ ] AI가 같은 자리에서만 쏘지 않는다.

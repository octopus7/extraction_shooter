# 전투 감각 작업 목록

## 목표

퀘스트가 없어도 20~30초 전투 자체가 재미있어야 한다.

## 플레이어 총기 피드백

- 총구 화염
- 발사음
- 총기 반동
- 약한 카메라 흔들림
- 탄환 궤적
- 탄피 배출
- 재장전 사운드
- 빈 탄창 피드백
- 조준선 또는 레이저 반응

## 적 피격 피드백

- 맞은 위치에서 스파크 또는 파편
- 피격 방향에 따른 움찔
- 피격음
- 순간 재질 플래시 또는 명도 변화
- 강한 공격의 큰 경직
- 사망 시 넘어짐, 파괴, 연기

## 플레이어 피격 피드백

- 피격 방향 표시
- 짧은 화면 반응
- 피격음
- 체력 UI 반응
- 첫 눈먼 탄 한 발로 즉사하지 않도록 밸런스
- 두 번의 교전을 무리하게 연속 진행하면 위험한 수준

## 환경 피격

최소 네 종류.

- 흙: 먼지
- 바위: 돌가루와 파편
- 나무 상자: 나무 조각
- 물: 물보라

## 루팅 피드백

- 아이템 드랍 시 짧은 튀어 오름
- 회전
- 반짝임
- 가까이 가면 살짝 떠오름
- 획득 사운드
- UI 팝업

## 파괴 오브젝트

상자 파괴를 추천한다.

```text
첫 타격
→ 금이 감
→ 추가 타격
→ 파괴
→ 아이템 드랍
```

## 전투 사운드

- 플레이어 총성
- 적 총성
- 근접 탄환 통과음
- 적 피격음
- 플레이어 피격음
- 표면별 탄착음
- 사망음
- 탄피 낙하음
- 재장전음
- 빈 탄창음

# Tuna Sweeper 플레이타임 배분

![Tuna Sweeper 플레이타임 배분 차트](playtime_breakdown_chart.png)

## 이미지 요약
- 일반 플레이 기준 목표 총합: **200분 (약 3시간 20분)**
- 실제 체감 목표: **약 3시간 30분 전후**
- 아래 표가 최신 SSOT 지역 개방 기준이다. 차트 이미지는 재생성 전까지 보조 참고용으로만 본다.

| 구역 | 목표 시간 | 역할 |
|---|---:|---|

| 맵 경로 언락 1 | 16분 | 중급 루트 개방 |
| 중급 파밍 / 보급품 회수 | 18분 | 장비 강화 기반 |
| 검문초소 / 상위 적 지역 | 22분 | 후반 관문 |

## 플레이타임 기준
- 빠른 플레이: **약 2.5시간**
- 일반 플레이: **약 3.3~3.7시간**
- 꼼꼼 플레이: **4시간+**

# 에디터 퀘스트 치트

에디터 상단 **TunaSweeper → Debug → 퀘스트 치트**에서 사용한다. 게임 실행이 끝난 뒤 현재 선택된 세이브 슬롯의 퀘스트 진행만 편집하는 개발 도구다. 패키징된 게임에는 포함되지 않는다.

1. 게임에서 편집할 슬롯을 선택하고 플레이를 종료한다.
2. 퀘스트 치트 창에서 표시된 데이터셋(Main/Demo)과 슬롯 번호를 확인한다. 슬롯 선택 기록이 없으면 기본 슬롯 1을 표시하며, 존재하지 않는 세이브를 새로 만들지는 않는다.
3. 양의 정수 퀘스트 ID를 입력한다.
4. **해당 퀘스트까지 완료** 또는 **선행 퀘스트만 완료**를 누른다.

첫 버튼은 모든 선행 체인과 지정 퀘스트를, 두 번째 버튼은 지정 퀘스트를 제외한 모든 선행 체인을 완료한다. 두 번째 버튼은 지정 퀘스트의 기존 상태를 유지한다. 여러 갈래로 합쳐지는 체인의 공통 선행 퀘스트는 한 번만 처리한다.

완료 상태는 `RewardCompleted`이며 목표별 수량도 필요한 수량으로 채운다. 완료된 퀘스트의 HUD 추적은 해제한다. 아이템·돈·경험치 보상, 대사 재생, 물리적인 시설 수리나 월드 진행 변경은 실행하지 않는다. 다음 로딩에서 완료된 퀘스트를 읽는 기존 시스템의 동작은 유지된다.

PIE, SIE, 실행 대기 상태, 에디터에서 실행한 별도 게임 창/Launcher 세션 중에는 입력과 버튼이 잠긴다. 버튼 실행 시에도 다시 검사한다. 플레이가 끝나면 잠금이 해제된다.

없는 ID, 없는 선행 정의, 순환 연결은 수정 전에 거부한다. 선택 슬롯 변경이나 손상된 선택 기록도 확인한다. 기존 세이브 편집 도구의 버전·데이터셋 검증과 원본 해시 비교를 거쳐 저장하고, 원본은 세이브 옆의 `.tool-backup-날짜-GUID` 파일로 보관한다. 성공 메시지가 나온 뒤 다시 게임을 시작하면 변경된 진행이 복원된다.

오류 메시지에는 진단 코드가 포함된다. `quest_not_found`는 없는 대상 ID, `quest_prerequisite_missing`은 없는 선행 정의, `quest_cycle`은 순환 연결, `save_unreadable`은 읽을 수 있는 기존 세이브가 없음, `stale_save`는 검사 이후 원본 변경을 뜻한다.

자동화 검사는 임시 세이브만 사용한다. 도구 구현·검증 과정에서 사용자의 실제 슬롯이나 프로젝트 퀘스트 정의, 웹 스냅샷을 변경하지 않는다.

# 99. 부록

## 용도

이 부록은 본 강의에서 반복해서 쓰는 용어, 체크리스트, 참고 경로를 모아 두는 곳이다. 본문 장에서 길게 설명하면 흐름을 끊는 자료를 이곳으로 분리한다.

## 용어 정리 후보

- 익스트랙션: 위험 구역에서 획득한 보상을 안전 구역으로 확정해 가져오는 행위.
- 벙커: 준비, 보관, 상점, 제작, 퀘스트가 일어나는 안전 허브.
- 레이드: 전투, 루팅, 탐색, 탈출 판단이 일어나는 위험 구역.
- 영속 상태: 저장/로드 후에도 유지되어야 하는 상태.
- 런타임 임시 상태: 현재 플레이 세션이나 현재 레벨에서만 필요한 상태.
- 아이템 정의: 모든 플레이어에게 동일한 정적 아이템 데이터.
- 아이템 인스턴스: 특정 세이브 슬롯 안에서 플레이어가 소유한 개별 아이템 데이터.

## 체크리스트 후보

### 새 기능을 강의에 추가할 때

- 기능이 어느 장의 주제인지 정한다.
- 실제 프로젝트 변경인지, 강의 설명만인지 구분한다.
- 저장 상태를 바꾸는 내용이면 실제 개발 문서와 충돌하지 않게 주의한다.
- 실습 목표가 1회 강의 안에서 확인 가능한지 점검한다.

### 새 시스템을 구현할 때

- Actor, Component, Subsystem, UI 중 어디가 상태를 소유하는지 정한다.
- 데이터 파일로 뺄 값과 코드에 남길 값을 나눈다.
- 저장해야 할 필드와 저장하지 않을 임시 값을 구분한다.
- 테스트할 성공/실패 경로를 적는다.

### 강의 자료를 실제 개발에 반영하려 할 때

- 강의 문서만 보고 바로 코드나 개발 문서를 수정하지 않는다.
- 실제 반영 요청을 별도로 만들고 변경 범위를 다시 검토한다.
- 기존 개발 문서와 코드가 우선 기준이라는 점을 확인한다.

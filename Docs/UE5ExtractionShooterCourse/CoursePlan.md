# 강의 운영 계획

## 적용 범위

이 문서는 `Docs/UE5ExtractionShooterCourse` 강의 문서의 운영 계획이다. 실제 `TunaSweeper` 개발 일정, 구현 우선순위, 코드 변경 계획으로 자동 전파하지 않는다. 강의 편의를 위해 단순화한 순서와 산출물은 교육용 기준이며, 실제 개발 기준은 기존 코드와 개발 문서를 우선한다.

## 과정 개요

- 대상: UE5 기본 조작과 C++ 기초를 알고 있는 수강자
- 목표: 탑다운 익스트랙션 슈터의 최소 플레이 루프를 이해하고, 기능별 시스템을 단계적으로 확장한다.
- 권장 구성: 15차시, 차시당 90~120분
- 강의 방식: 개념 설명, 프로젝트 구조 읽기, 최소 실습, 확인 과제 순서
- 기준 프로젝트: `TunaSweeper/TunaSweeper.uproject`

## 전체 산출물

- 벙커와 레이드 맵을 오가는 최소 익스트랙션 루프 설계안
- 플레이어 이동, 조준, 상호작용, 루팅, 탈출 흐름의 기능 분해 문서
- 아이템 정의와 아이템 인스턴스를 구분한 인벤토리 설계안
- 전투, 적 AI, 저장, UI, 에디터 도구의 역할 분리 체크리스트
- 강의용 미니 프로젝트나 실습 브랜치에 적용할 단계별 구현 계획

## 실습 진행 순서

1. 프로젝트 구조를 읽고 기준 문서 위치를 확인한다.
2. 플레이어 이동과 카메라 기준을 먼저 정한다.
3. 상호작용 대상 탐색과 실행 흐름을 만든다.
4. 아이템 정의와 플레이어 인벤토리 모델을 만든다.
5. 루트 컨테이너에서 인벤토리로 아이템을 옮기는 흐름을 연결한다.
6. 벙커에서 레이드로 이동하고, 레이드에서 추출 지점으로 복귀하는 흐름을 만든다.
7. 성공 복귀와 실패 복귀의 저장 결과를 분리한다.
8. 무기 발사, 투사체, 피해 처리, 적 AI를 붙인다.
9. HUD, 인벤토리, 상점, 퀘스트 UI를 필요한 순서로 확장한다.
10. 테스트 체크리스트와 밸런스 표로 반복 검증한다.

## 세부 문서 작성 순서

1. `00_Orientation`과 `01_UEProjectSetup`을 강의 원고 형식으로 먼저 확장한다.
2. `03_PlayerCharacterCameraInput`, `04_InteractionSystem`, `05_ItemsInventoryLoot`, `08_RaidExtractionFlow`를 최소 플레이 루프 중심으로 확장한다.
3. `06_CombatWeaponsDamage`와 `07_EnemyAIEncounters`를 전투 루프 중심으로 확장한다.
4. `09_SaveLoadPersistence`와 `11_UIUXHUDMenus`를 플레이어 경험 안정성 중심으로 확장한다.
5. `10_WorldMapsLevelDesign`, `12_AssetsMaterialsVFXAudio`, `13_EditorToolsAutomation`, `14_TestingBalancingPackaging`을 제작 품질과 운영 단계로 확장한다.
6. `99_Appendices`에 용어, 체크리스트, 자주 틀리는 구조를 모은다.

## 각 장의 권장 내부 구성

- 강의 목표
- 시작 전 확인
- 개념 설명
- 기준 프로젝트 관찰 지점
- 최소 실습
- 흔한 실수
- 확인 과제
- 다음 장과 연결되는 질문

## 운영 메모

- 강의 본문은 실제 코드의 모든 예외를 다루지 않고, 초보자가 시스템 책임을 이해할 수 있는 수준으로 정리한다.
- 실제 프로젝트와 다른 단순화가 들어가면 "강의용 단순화"라고 명시한다.
- 저장 데이터, 런타임 스폰, 좌표/단위 기준은 기존 개발 문서를 참조하고 강의 문서에서 독자적으로 기준을 바꾸지 않는다.
- 코드 실습을 추가할 때는 먼저 문서 실습 목표를 확정하고, 그 다음 최소 코드 변경 단위를 정한다.

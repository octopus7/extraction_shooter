# 12. 에셋, 머티리얼, VFX, 오디오

## 학습 목표

- 게임플레이 기능과 시청각 표현을 분리해 관리하는 방식을 배운다.
- 아이콘, 머티리얼, 이펙트, 사운드가 시스템 피드백에 어떻게 연결되는지 이해한다.
- 강의용 임시 에셋과 실제 프로젝트용 에셋 제작 기준의 차이를 구분한다.

## 강의 흐름

1. 아이템 아이콘과 UI 텍스처 기준을 설명한다.
2. 무기 명중, 근접 공격, 폭발, 레벨 전환 같은 이펙트 연결 지점을 설명한다.
3. 머티리얼은 시각 품질뿐 아니라 피드백과 판독성에도 영향을 준다는 점을 설명한다.
4. BGM, UI 사운드, 상호작용 사운드를 게임 상태와 연결하는 방식을 설명한다.

## 핵심 개념

- 아이템 아이콘은 데이터와 UI를 연결하는 대표적인 시각 식별자다.
- VFX는 실제 규칙을 대신하지 않고, 규칙이 발생했음을 보여주는 피드백이다.
- 머티리얼은 레벨 분위기, 가독성, 충돌 판독, 상호작용 가능성 표시를 모두 담당할 수 있다.
- 오디오는 전투 위험, 상호작용 성공, UI 전환, 공간 분위기를 보조한다.
- 생성형 이미지나 임시 에셋은 강의용 이해에는 좋지만 실제 프로젝트에는 별도 검수와 정리가 필요하다.

## 실습

- 아이템 3개를 정하고 아이콘, 이름, 카테고리, 희귀도 색을 연결해 본다.
- 폭발 드럼통의 파괴 피드백을 메시 교체, 이펙트, 사운드, 피해로 나누어 적는다.
- 상호작용 가능한 오브젝트와 배경 오브젝트를 시각적으로 구분하는 기준을 정한다.

## 확인 포인트

- VFX가 실제 피해 판정을 대신하면 안 되는 이유를 설명할 수 있다.
- UI 아이콘 크기와 일관성이 인벤토리 사용성에 미치는 영향을 이해한다.
- 사운드와 시각 피드백이 같은 게임 이벤트에 맞춰 재생되어야 한다는 점을 설명할 수 있다.

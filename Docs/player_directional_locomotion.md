# 플레이어 방향별 이동 모션

## 2026-11-21 게임 적용

플레이어의 양손이 비어 있으면 `ABP_LunaMk2`가 `Unarmed/BS_Luna_Unarmed`를 사용한다. 무기를 장착하면 기존 무장 이동 상태로 전환한다. 두 경로는 같은 구르기 몽타주 슬롯을 거친다.

이동 각도는 캐릭터가 바라보는 방향을 기준으로 계산한다. 정면은 0도, 오른쪽은 +90도, 왼쪽은 −90도이며 후진은 ±180도에서 이어진다. 블렌드 스페이스의 세 행은 비무장 대기, 걷기, 뛰기다. 실제 수평 이동 속도와 현재 허용 속도, 질주 상태로 행 사이를 보간한다.

`TunaSweeper.Player.DirectionalLocomotion`은 27개 방향·보행 샘플 지점, 무장 이동과 구르기 슬롯 연결, 실제 플레이어 메시의 비무장 횡이동 포즈를 검증한다.

## 2026-11-20 비무장 이동 모션 검토본

[Blender 원본](../TunaSweeper/SourceArt/Characters/LunaMk2/DirectionalMotions/LunaMk2_Unarmed.blend)에서 루나 Mk2의 비무장 대기와 방향별 걷기·뛰기 액션을 선택할 수 있다. [비교 영상](../TunaSweeper/SourceArt/Characters/LunaMk2/DirectionalMotions/LunaMk2_Unarmed_8Way.mp4)은 루나 기준 여덟 방향을 각각 2초씩 보여준다.

24fps 기준 걷기 한 주기는 24프레임, 뛰기는 16프레임이다. 대각선은 전후·좌우 성분을 합성한 발 궤적으로 제작했다. 기존 방향별 시퀀스 3개와 방향 Blend Space는 삭제했다. 이 단계에서는 기존 속도 기반 이동을 사용했고 새 모션 적용과 블렌딩은 영상 검토 후로 보류했다.

## 이전 제작 기록

2026-09-20: LunaMk2 플레이어에 후진 및 좌우 횡이동의 최초 연결 버전을 추가했다.

당시 적용 상태: 사용자 요청으로 `ABP_LunaMk2`를 연결 직전 버전으로 복원했다. 플레이어는 기존 `BS_RunWalk` 기반 속도 전용 로코모션을 사용한다. 아래 생성 모션 3개와 `BS_DirectionalWalk`는 삭제하거나 변경하지 않고 미연결 에셋으로 보관한다. 아래 제작·연결 설명은 최초 제작 당시 기록이다.

2026-09-21 재점검에서 플레이어 AnimBP 파일이 다시 생성 모션 연결 당시 버전과 일치함을 확인해 원본을 재복원했다. 플레이어 BP의 실제 AnimClass와 저장된 그래프를 새 프로세스에서 확인했다. 타이틀은 별도 `Title/ABP_LunaMk2_Title`을 사용하며, 이번 복원에서는 타이틀 모션과 연결을 수정하지 않았다.

## 에셋과 연결

`/Game/Characters/Player/LunaMk2/Animations/`:

- `AS_Luna_WalkBackward`: 후진 루프
- `AS_Luna_StrafeLeft`, `AS_Luna_StrafeRight`: 좌우 사이드스텝 루프
- `BS_DirectionalWalk`: X축 방향(-180~180도), Y축 속도(cm/s)
- `ABP_LunaMk2`: 기존 Walk 상태의 Blend Space를 교체하고 소유 액터의 속도와 회전으로 `LocomotionDirection`을 계산한다.

기존 정면 걷기/빠른 이동 샘플과 Idle 상태, 구르기 슬롯, 후단 머리/물리 처리는 유지한다. 캡슐 이동속도는 변경하지 않는다. 현재 플레이어 BP의 기본 이동속도는 200cm/s이다. 후진 경계 양쪽(-180/+180)에 같은 모션을 놓아 방향 경계의 포즈 점프를 방지한다.

## 제작 기준과 제한

기존 라이플 대기 자세를 바탕으로 다리의 고정 길이 IK, 발목 궤적, 작은 골반 이동을 베이크했다. 세 모션은 60fps, 0.8초 루프이고 루트 이동은 없다. 역재생만 적용한 모션은 아니다.

후진 보폭은 38cm, 횡이동 보폭은 22cm이며 발을 들어 옮기는 높이는 7cm다. 지지 구간 0.4초 동안의 발 이동속도(후진 95cm/s, 횡이동 55cm/s)에 맞춰 Blend Space의 샘플 재생속도를 설정한다. 횡이동은 짧은 보폭이므로 게임 속도에서는 발걸음이 빠르며, 초기 연결 버전의 보폭·리듬은 플레이 감상에 따라 추가 조정할 수 있다. 지형 접지 IK나 별도의 후진/횡이동 달리기 모션은 이번 작업에 포함되지 않는다. 대각선에서는 인접 방향 모션을 혼합한다.

## 검증

- `TunaSweeper.Player.DirectionalLocomotion`: 보관된 모션의 루프 경계, 유효한 본 변환, 방향별 선택, 재생속도 및 플레이어가 원래 `BS_RunWalk`를 사용하는지 확인한다.
- `TunaSweeper.Player.DirectionalPoseCapture`: 저장된 모션을 실제 플레이어 메시에서 평가하고 발 이동을 검사하며 12개 포즈를 `Saved/DirectionalLocomotion/Capture`에 렌더링한다. 렌더링 가능한 별도 에디터 프로세스에서 실행한다.

생성·재생속도 보정 코드는 에셋과 함께 먼저 커밋한 뒤 다음 커밋에서 제거한다. 최종 소스에는 검증 코드만 남긴다.

# 보스 연구실

## 진입

메인 메뉴의 **연구실**에서 다음 기능을 선택한다.

- **보스개발**: 부품 조립, 전술 설정, 보관 및 싱글 시험.
- **보스플레이(싱글)**: 보관한 보스 슬롯을 불러와 전투.
- **보스플레이(멀티)**: `개발 중` 토스트. 온라인 로그인·매칭·동기화는 실행하지 않는다.

연구실은 `/Game/Maps/BossCombatTestMap`을 `TunaSweeperBossLabGameMode`로 연다. 이 모드에서는 기존 시험 보스와 워프를 제거하고 모듈 보스 하나를 편집·시험한다.

## 조립과 전투

코어, 프레임, 장갑, 구동부, 기관포, 미사일, 레이저를 제공한다. 부품을 선택하고 부모 부품·연결 방향·90도 단위 회전을 지정하여 추가한다. 선택된 부품을 제거하면 그 아래 연결한 부품도 함께 제거한다. 코어는 제거할 수 없다.

전술은 균형·거리 유지·접근, 공격 간격, 2페이즈 전환 체력, 무기 교대 여부를 설정한다. 전투 중 부위 내구도와 파괴 상태는 편집 초안을 변경하지 않는다. 코어 파괴는 승리, 플레이어 사망은 패배로 처리하고 작업 화면으로 돌아간다. `Home` 또는 `Esc`로 시험을 중단할 수 있다. 시험 중 예비 탄약을 보충하며 재장전은 기존 방식대로 수행한다.

초기 외형은 내장 기본 도형으로 조립한다. 부품 선택 강조와 미리보기 회전으로 구조를 확인한다. 자유 물리 보행이나 사용자 제작 모델 가져오기는 제공하지 않는다.

## 슬롯과 파일 복사

보스 보관함은 본편 진행 세이브와 독립된 12개 슬롯이다. 쓰기 가능한 프로젝트 저장 경로 아래 다음 파일을 사용한다.

```text
Saved/BossLab/Demo/Slot01.boss.json
Saved/BossLab/Demo/Slot02.boss.json
...
Saved/BossLab/Main/Slot12.boss.json
```

현재 빌드에 따라 Demo 또는 Main 폴더를 사용한다. 작업 화면의 폴더 열기를 이용하면 실제 저장 위치에 접근할 수 있다. 다른 사람이 만든 파일을 빈 슬롯 이름으로 복사한 뒤 목록을 새로고침하고 불러오면 된다. 파일 이름은 `Slot01.boss.json`부터 `Slot12.boss.json`까지다. 슬롯 13 이상은 인식하지 않는다.

파일 하나에 전체 설계가 들어 있으며 별도 목록 데이터베이스를 요구하지 않는다. 외부에서 파일을 복사할 때는 게임을 종료하거나 해당 파일을 저장 중이지 않은 시점에 작업한다. 기존 슬롯 이름으로 복사하면 그 슬롯을 교체하므로 원본을 먼저 보관한다.

이름 최대 64자, 부품 최대 32개, 연결 깊이 최대 8, JSON 최대 256 KiB다. 알 수 없는 부품/버전, 중복 ID/연결부, 순환 연결, 과도한 크기, 겹치는 부품, 범위를 벗어난 전술은 거절한다. 잘못된 파일을 불러와도 기존 초안과 파일은 보존한다.

## 구현 경계

- `TunaSweeperBossDefinition`: 고정 카탈로그 ID와 순수 설계도, 검증, JSON 변환, 연결 변환.
- `TunaSweeperBossLabSubsystem`: 슬롯 파일과 이번 실행의 편집 초안.
- `TunaSweeperModularBoss`: 부품 충돌체·내구도·전술·무기 실행.
- `TunaSweeperBossLabGameMode`: 미리보기, 시험 시작/중단, 임시 플레이어 장비, 타이틀 복귀.
- `TunaSweeperBossLabWidget`: 로컬 편집/슬롯/전투 진입 UI.

미래의 코옵을 위해 정의와 런타임 상태, 안정적인 부품 인스턴스 ID, 검증 제한을 분리했다. EOS/네트워크 전송/RPC/복제/호스트 이전은 구현하지 않았다.

시험 중에는 기존 combat-test 저장 보호를 유지한다. 시험 장비·탄약·경험치를 본편 슬롯에 저장하지 않고 연구실 종료 시 원래 상태를 복구한다. 기존 연구/캐릭터 진행에 따른 능력치까지 표준화하는 별도 경쟁 규칙은 없다.

## 검증 명령

UE 에디터 자동화 필터 `TunaSweeper.BossLab` 및 `TunaSweeper.UI.Title.LaboratoryNavigation`을 사용한다. 기존 `TunaSweeper.Combat.BossEncounter`와 제목 화면/현지화 테스트도 함께 확인한다.

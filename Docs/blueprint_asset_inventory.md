# 블루프린트 애셋 전수 목록 및 기능 요약

- 조사 기준: 2026-10-07, TunaSweeper UE 5.7 프로젝트의 현재 작업 폴더. 에디터 조회 버전은 5.7.4.
- 조사 범위: `TunaSweeper/Content`와 공개 로컬 플러그인의 `Content` 폴더. 독립 `.uasset` **1,709개**를 검사해 **블루프린트 122개**를 확인했다.
- 실제 UE AssetRegistry 및 로드/CDO 조회: **121개 성공**. 나머지 `RaidLevelKit` BP 1개는 저장된 애셋 타입·부모 태그와 C++ 소스로 보완했다.
- 블루프린트처럼 이름 붙은 **ObjectRedirector 2개**는 아래 별도 목록에 기록했다. 실제 BP 수에 중복 합산하지 않았다.
- 엔진 설치 콘텐츠와 access-restricted `ProductionPayload` 저장소는 제외했다. `.umap` 내부 LevelScriptBlueprint는 독립 블루프린트 애셋 목록에 포함하지 않았다.

## 읽는 방법과 조사 한계

- 각 행 첫 열은 Unreal 패키지 경로이며 링크 대상은 실제 `.uasset` 파일이다. 예를 들어 `/Game/UI/WBP_GameHud`는 `TunaSweeper/Content/UI/WBP_GameHud.uasset`이다. 객체 경로는 패키지 경로 뒤에 `.애셋이름`, 생성 클래스 경로는 `.애셋이름_C`가 붙는다.
- 부모 클래스의 `모듈.클래스` 표기는 `/Script/모듈.클래스`를 줄인 것이다. 부모가 다른 BP인 경우 해당 생성 클래스 경로를 그대로 표시했다.
- 기능 설명은 부모 클래스의 현재 C++ 헤더·구현, 애셋의 부모/타입 태그, CDO 공개 설정 및 컴포넌트, 실제 조회한 그래프 이름, 직렬화 NameMap의 노드·함수·참조 이름을 종합한 개략 요약이다. C++ 근거 링크로 상속 기능의 구현을 확인할 수 있다.
- `IsDataOnly=True`는 저장 레지스트리 기준 설정 중심 BP다. `False`만으로 자체 실행 로직이 있다고 단정하지 않는다. 위젯 디자이너와 애니메이션 그래프도 함께 고려해야 한다.
- UE Python API에서 그래프 목록·신규 변수 일부가 비노출이고 그래프 `Nodes`는 protected여서 **모든 노드 연결·분기·핀을 해석한 조사는 아니다**. 노드/함수 이름 흔적은 저장된 식별자의 존재를 뜻하며, 실제 실행 연결을 입증하지 않는다. 순수 Actor/AnimInstance 기반 BP의 세부 동작 설명은 이 한계 안에서 읽어야 한다.
- CDO는 설치된 바이너리와 저장 애셋 기준이며 기능 설명의 소스는 현재 작업 폴더 기준이다. 미빌드 소스와 런타임 바이너리의 일치, 현재 레벨에서의 사용 여부, PIE/패키지 플레이 동작은 검증하지 않았다.
- `RaidLevelRuntime` 바이너리가 없어 조회 프로세스에서만 `RaidLevelKit`을 비활성화했다. 프로젝트 설정·소스·애셋은 수정하지 않았다.
- 소스 기능 조사 2개 범위와 UE 추출을 병렬 수행하고, 별도의 전체 디스크 메타데이터 검사로 **122개 경로 일치·기능 요약 누락 0개**를 확인했다. 조사 전후 `.uasset`/`.umap` 1,744개의 SHA-256도 대조했다.

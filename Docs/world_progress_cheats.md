# 월드 진행 치트

에디터 상단 **TunaSweeper → 월드 진행 치트**에서 마지막으로 선택한 데이터셋·슬롯의 월드 상태를 항목별로 편집한다. 플레이 중에는 비활성화하며, 저장 변경은 다음 플레이에서 해당 슬롯을 불러올 때 적용한다.

- **초기화**: 선택 ID를 명시적인 `InProgress`, 수량 0으로 저장한다. 기록을 삭제하지 않으므로 과거 퀘스트 보상을 이용하는 시설 복구 보정이 이를 다시 완료시키지 않는다.
- **미완료로 적용**: 입력한 수량과 `InProgress`를 저장한다. 터널 낙석은 수량 1이 장전 상태이며 다음 로드에서 폭파 카운트다운이 재개된다.
- **완료로 적용**: `Completed`와 완료에 필요한 수량 이상을 저장한다. 고정 배치 항목은 카탈로그의 수량 범위로 제한한다.

현재 배치된 10개 ID는 `TunaSweeper/Config/WorldProgressCheats.json`에 등록한다. 기지 배관, 레이드 리프트, 숲–마을 낙석, 숲–평원 승강기, 숲 전력 시설, ATV 창고 전력, 에탄올 시설, 서·북·동역 윤활이다. 아직 저장 기록이 없는 항목도 표시한다. 기존 저장에만 있는 다리·영구 개방 문 등은 ID별 추가 행으로 표시하며 수량도 직접 편집할 수 있다. 신규 배치·ID·수량 변경 시 카탈로그를 갱신한다. 기지 배관은 현재 맵의 액터 이름 대체 ID를 그대로 사용한다.

데모 취수구 이물질 제거·밸브 수리는 목록과 변경 API에서 제외한다. `demo.water_intake.*` ID 및 취수구/밸브 InfoId를 가진 기존 기록도 편집하지 않는다.

퀘스트 진행·보상·아이템은 직접 수정하지 않는다. 다음 로드에서 기존 게임 규칙이 월드 완료를 퀘스트 목표로 인정할 수 있지만 이미 인정한 목표는 월드 초기화만으로 되돌아가지 않는다. 목표도 되돌리려면 퀘스트 치트를 별도로 사용한다. 철도는 기존 공유 동작을 유지하므로 **미윤활로 되돌릴 때 세 역을 모두 초기화한 뒤 플레이**한다. 한 역의 완료가 남아 있으면 재진입 때 전체 윤활로 보정된다.

각 변경은 화면에 표시된 원본 해시·슬롯을 재확인하고 `.tool-backup-*` 원본 백업을 만든 뒤 기존 fail-closed 저장 경로로 기록한다. 파일이 그사이 변경되면 거절하고 목록을 새로 읽는다. 전체 초기화·보상 지급·재료 환급은 수행하지 않는다.

오프라인 저장 API는 `world-inspect`와 `world-set`을 제공한다. `world-set`은 `objectId`, `state` (`InProgress` 또는 `Completed`), 정수 `quantity`를 받으며, 실제 기록에는 `commit: true`와 조회 결과의 `expectedHash`가 필수다. 카탈로그나 기존 저장에 없는 새 ID, 잘못된 상태·수량, 중복/잘못된 기존 월드 ID는 거절한다. API와 UI는 에디터 전용이며 실제 사용자 세이브를 테스트 픽스처로 사용하지 않는다.

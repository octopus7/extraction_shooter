# 복셀 임시 캐릭터 모델링 기준

아기멧돼지와 해병·해적 고양이 같은 복셀 임시 캐릭터에 적용한다. 일반 로우폴리 모델의 펼친 UV와 표면 디테일 텍스처 제작 규칙과 구분한다.

- 캐릭터 한 개의 머리, 귀, 모자, 팔다리, 꼬리와 장비를 모두 최대 `32 × 32 × 32` 셀 안에 넣는다. 서로 다른 부품마다 새 32³ 격자를 할당해 제한을 늘리지 않는다.
- 모든 표면 꼭짓점은 동일한 정수 복셀 격자 위에 둔다. 셀 크기는 캐릭터의 게임 크기에 맞게 정하고 원본 manifest에 cm 단위로 기록한다. 아기멧돼지는 2cm, 해병·해적 고양이는 3cm 셀을 사용한다.
- 겹친 셀의 내부 면은 만들지 않는다. 같은 평면·색상의 인접 표면은 직사각형으로 합쳐 실루엣을 유지하면서 면 수를 줄인다. 윤곽은 각진 복셀 형태를 유지한다.
- 렌더 메시에는 머터리얼 슬롯 하나와 불투명 팔레트 텍스처 하나만 사용한다. 색마다 머터리얼을 추가하거나 버텍스 컬러만으로 색을 지정하지 않는다. 같은 팔레트를 쓰는 여러 캐릭터가 텍스처와 머터리얼을 공유해도 된다.
- UV0의 각 면은 지정 색상 칸 내부에 들어가는 작은 사각형으로 매핑한다. 사각형은 면적을 가져야 하며 UV를 점이나 선으로 축소하지 않는다. 칸 경계에서 여백을 두고, 팔레트는 nearest 필터와 mipmap 없음으로 설정해 인접 색이 섞이지 않게 한다. 의도적인 팔레트 UV 중첩을 일반 텍스처 아틀라스 오류로 취급하지 않는다.
- 전방은 +X, 위는 +Z다. 바닥은 Z=0이며 피벗은 캐릭터 아래에 둔다. Blender 미터 장면에서 내보낸 FBX는 cm 메타데이터를 유지한다. UE 임포트 후 축과 크기를 다시 검사한다.
- FBX 축 옵션만 보고 캐릭터의 실제 시선 방향을 추측하지 않는다. 고양이는 Blender에서 실제 +X를 바라보고, FBX 내보내기 `axis_forward=-Y`, `axis_up=Z`, UE 임포트 `force_front_x_axis=false`, 회전 보정 0도를 사용한다. 다른 모델의 저작 좌표 변환이나 임포트 회전값을 그대로 복사하지 않는다. 눈·코 등 전면 위치와 FBX 축 메타데이터·노드 회전을 함께 확인한다.
- 머리·모자·옷의 큰 색 영역과 실루엣으로 역할을 구별한다. 작은 장식만으로 구분하지 않는다. 임시 모델은 고정 포즈를 허용한다.
- 원본 `.blend`, FBX, 팔레트 PNG, 미리보기와 `model_manifest.json`을 SourceArt에 보관한다. manifest에는 셀 크기·격자 범위·메시 크기·삼각형 수·머터리얼과 UV 수·팔레트 크기·전방 축을 기록한다.
- 저장한 blend와 내보낸 FBX를 새 Blender 프로세스에서 열어 크기, 정수 격자, UV 면적, 유한한 노멀·탄젠트, 머터리얼 수를 검증한다. UE에서도 저장 후 다시 로드해 메시와 머터리얼 연결, BP 외형·충돌·상호작용 위치를 확인한다.
- 일회성 생성기와 임포트 스크립트는 작업용 임시 경로에 두고 완료 소스에 포함하지 않는다. 런타임이나 에디터 시작 시 재생성하는 경로를 남기지 않는다.

현재 고양이 원본은 `TunaSweeper/SourceArt/Characters/FactionCats`, UE 저장 경로는 `/Game/Characters/FactionCats`다. 두 고양이는 `T_FactionCatsPalette`와 `M_FactionCats`를 공유한다. `BP_MarineCat`과 `BP_PirateCat`은 상시 표시하는 `TunaSweeperFacilityNpcActor`를 부모로 사용한다. 퀘스트 진행에 따라 숨는 아기멧돼지의 등장 역할 BP를 그대로 복제하지 않는다.

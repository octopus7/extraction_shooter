# Tuna Sweeper 스토리 영상 컷 추천

## 목적

이 문서는 스토리 진행 중 유저에게 보여줄 짧은 동영상 컷 후보를 정리한다.

각 컷은 5초 또는 10초 이내의 짧은 영상으로 나누는 것을 전제로 한다. 기준은 게임 내 캐릭터 조작이나 대화 연출보다, 영상으로 압축했을 때 분위기와 감정 전달이 더 강한 장면이다.

## 연출 방향

Tuna Sweeper 본편의 핵심은 거대한 세계관 폭로가 아니라, 숲속 벙커에서 깨어난 루나가 단일 대형 맵의 구역을 익숙하게 만들고 벙커 생활을 안정화하는 이야기다.

따라서 영상 컷은 다음 방향을 우선한다.

- 세계의 진실을 설명하기보다 상태와 분위기를 보여준다.
- 루나의 정체나 POD-02의 비밀을 직접 밝히지 않는다.
- 벙커가 어두운 대피소에서 따뜻한 집으로 변하는 과정을 반복해서 각인한다.
- 참치캔은 개그 소품이면서도 생활 보급품이라는 감정 축을 유지한다.
- 컷신은 길게 끌지 않고 챕터 전환, 보상, 위협의 원인, 엔딩 감정에만 사용한다.

## 컷별 세부 메모

### 1. 동면 장치 내부 기상

- 화면은 흐린 유리, 물속 빛 알갱이, 손상된 HUD를 중심으로 구성한다.
- 루나 전신을 보여주기보다 눈, 손가락, 상태등 같은 일부만 보여주는 편이 비용 대비 효과가 좋다.
- 텍스트는 최소화한다.

예시 화면 텍스트:

```text
POD-01: SUPPORT UNIT
STATUS: AWAKENED
MEMORY RECORD: DAMAGED
```

### 2. POD-02와 빈 POD-03

- POD-02는 열지 않는다.
- POD-03는 빈 장치라는 사실만 보여준다.
- 카메라는 설명하듯 훑지 말고, 상태등과 빈 내부를 짧게 스치듯 보여주는 편이 좋다.

예시 화면 텍스트:

```text
POD-02: STASIS ACTIVE
BIO SIGNAL: STABLE
WAKE AUTHORITY: NONE
```

### 3. 벙커 조명 복구

- 컷 초반은 거의 암전 상태로 시작한다.
- 조명이 켜질 때 참치 선반, 작업대, 두더지가 차례로 드러나면 챕터 보상감이 좋다.
- 이 컷은 앞으로 벙커 복구 연출의 기준 샷으로 재사용할 수 있다.

### 4. 돌아오는 문 개방

- 서쪽 우회로 끝에서 닫힌 문을 열어 초기 구역으로 이어지게 한다.
- "새 지역"보다 "같은 맵이 짧아짐"을 보여주는 컷이다.
- 문 너머로 벙커 방향 불빛이나 익숙한 초반 숲길을 보이게 한다.

### 5. 오늘의 식탁 준비

- 보스 처치 자체보다 그 뒤에 고급참치와 식탁 준비가 갖춰지는 순간을 보여준다.
- 화면 정보는 "고급참치", "오늘의 식탁", "거주 가능 상태" 같은 일상 안정화 기준으로 제한한다.
- 다음 지역 좌표나 대형 세계관 폭로를 보여주지 않는다.

### 6. 첫 저녁

- 가장 중요한 엔딩 컷이다.
- 가득 찬 참치 선반, 따뜻한 조명, 작은 식탁, 빈 접시 하나를 반드시 포함한다.
- POD-02 상태등이 마지막에 천천히 한 번 깜빡이면 후속 떡밥을 설명 없이 남길 수 있다.

예시 엔딩 화면 텍스트:

```text
첫 저녁 완료
거주 가능 상태 달성
```

## 최소 제작 세트

제작 리소스를 줄여야 한다면 아래 6개만 우선 제작한다.

1. 동면 장치 내부 기상
2. POD-02와 빈 POD-03
3. 벙커 조명 복구
4. 돌아오는 문 개방
5. 정착 단서 확보
6. 첫 저녁

이 세트는 오프닝, 미스터리, 초반 보상, 맵 접힘, 최종 정착 조건, 엔딩 감정을 모두 포함한다.

## 확장 제작 세트

챕터 전환마다 짧은 보상 컷을 넣고 싶다면 아래 5개를 추가한다.

1. 벙커 문 개방
2. 고급보안구역 접근
3. 콘크리트 더미 제거
4. 북쪽 고지대와 낙하 루트
5. 보스 구역 개방

확장 세트는 플레이 흐름을 더 풍성하게 만들지만, 본편 감정선의 필수 요소는 아니다.

## 사용하지 않는 편이 좋은 컷

아래 장면은 짧은 영상으로 만들 경우 본편의 기대치를 과하게 키우거나 제작 비용 대비 효과가 낮을 수 있다.

- 숲 바깥의 대규모 멸망 도시 전경
- POD-02 내부 존재의 얼굴 공개
- 루나의 제작 목적을 암시하는 긴 회상
- 대규모 군사 시설 또는 전쟁 장면
- 후속 지역을 직접 예고하는 엔딩 후 영상

본편에서는 "세계를 구했다"가 아니라 "오늘 밤 돌아올 집을 만들었다"는 감정이 남아야 한다.

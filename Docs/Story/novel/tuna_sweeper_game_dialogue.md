# Tuna Sweeper 게임용 대사집 초안
## 기준
- 소설판과 별개로, 게임 안에서 일부만 짧게 보여주는 대사집.
- 대화는 긴 만담이 아니라 2~6줄 단위의 짧은 이벤트 대사.
- 정황 묘사는 최소화하고, 트리거/퀘스트 목표/대사로 이해되게 구성.
- 두더지는 반말. 루나는 짧고 순진한 반응 위주.
- 밝은 일상 생존물 톤. 암울한 설명은 배경 소품 수준으로만 처리.

---

# 0. 캐릭터 말투 기준

## 루나
- 짧고 직접적인 문장.
- 처음 보는 것을 그대로 받아들이고 이름 붙임.
- “이거 뭐야?”, “맛있어.”, “또 찾자.” 같은 단순한 반응.
- 감정은 크지만 과장된 만담은 줄임.

## 두더지
- 반말.
- 루나를 챙기는 동료답게 목표와 위험을 알려준다.
- 잔소리는 짧게.
- 농담은 한 줄로 끝낸다.
- 루나를 너무 놀리거나 길게 받아치지 않는다.

# 14. 게임 이식 메모

- 모든 대사를 한 번에 보여주지 말고, 상호작용 시 2~4줄만 출력.
- 두더지가 너무 많이 받아치면 만담처럼 느껴지므로, 설명 대사는 UI 목표 문장으로 빼는 편이 좋다.
- 루나의 감상은 짧게 남기고, 해석은 플레이어가 하게 둔다.
- 소설판의 감정선은 게임에서는 물건/지도/상자/화분 변화로 보여준다.
- 떡밥은 “북쪽 그림자”, “대형 보행 장비”, “북쪽 경계 구역” 정도만 남기고 메인 목표로 띄우지 않는다.

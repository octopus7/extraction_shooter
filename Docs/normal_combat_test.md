# 일반 전투 실험실 — 진행 중

## 현재 구현

- 맵: `/Game/Maps/NormalCombatTestMap`. 32×26m 공간에 엄폐물 4개와 측면 이동로, 플레이어 시작점, 일반 적 생성 지점 3개가 있다.
- `ATunaSweeperCombatLabGameMode`가 일반 사족 보행 소총 적 3명을 생성한다. 전멸·플레이어 사망·90초 제한 종료 후 2초 뒤 다음 라운드를 시작한다.
- `UTunaSweeperCombatLabAutopilotComponent`는 실제 플레이어 이동·조준·발사·재장전·구르기 함수를 사용한다. 피해를 직접 주입하지 않는다. 내비게이션 경로, 시야 검사, 타깃 유지, 점사, 접근 탄환 회피를 구현했다.
- F6 자동/수동 전환, Home 라운드 재시작, 기존 F8 적 상태 표시를 연결했다. F6 실제 입력 검증 중 사용자가 컴퓨터 사용을 중단하여 전환 성공은 미확인이다.
- 기존 테스트 세션의 임시 장비와 저장 차단을 사용한다. AI 상태·라운드·측정치는 게임 세이브에 추가하지 않는다.
- UI 문자열은 `Content/Data/UITextStrings.csv`의 `ui.combat_lab.*` 키로 한국어·영어·일본어를 제공한다.
- `Saved/CombatLab/*_rounds.csv`에 라운드 시간, 양측 발사 탄환 수, 체력 감소 샘플 수, 양측 피해, 이동 거리, 정지 시간, 회피 횟수를 기록한다. `damage_samples`는 프레임별 체력 감소 횟수이며 개별 탄환의 명중 횟수와 같지 않다.

## 남은 작업 — 우선순위

1. **HUD 글자 누락 수정.** 배경 패널만 보인다. UE 5.7 `FCanvasSimpleTextItem`은 `Font != nullptr`일 때만 그린다. 현재 프로젝트 `TunaSweeperUIFont::MakeFont`는 `FontObject=nullptr`와 CompositeFont를 반환하므로 SlateFontInfo 생성자에서 유효한 UFont가 만들어지지 않는다. 프로젝트 글꼴·문자열 키를 유지한 채 유효한 런타임 폰트 또는 기존 위젯 렌더링으로 연결하고 세 언어를 확인한다.
2. **라운드 사이 카메라 유지.** `FinishRound`에서 플레이어를 즉시 제거해 다음 생성 전 화면이 검게 보이거나 바닥만 비친다. 전투 종료와 플레이어 교체 시점을 분리하고 카메라를 유지한다. 사망 후 원래 벙커 이동 타이머도 함께 검증한다.
3. **교전 평가 조건 조정.** 플레이어 AI 인지 거리는 1,800cm, 일반 소총 적의 추적 거리는 1,150cm다. 선제 사격으로 적이 대응하기 전에 죽는 현상을 우선 해소한다. 적 체력만 늘려 시간을 채우지 말고 인지·조준 반응·위치 이동·사격 기회를 측정한다.
4. **1시간 이상 실제 개선 반복.** 수정 전후 동일 조건으로 여러 라운드를 관찰한다. 무피해 승리뿐 아니라 피격·사망·재장전·엄폐 접근·우회·정체·근접 탄환 회피를 확인한다. 필요에 따라 공격 예고, 피격 반응, 사운드, 이펙트·메시·텍스처를 개선한다. 현재 새 전투 이펙트나 적 모델을 추가한 상태는 아니다.
5. **입력·수명주기 검증 보강.** F6 수동 전환, Home 초기화, 사망 재시도, 90초 타임아웃, 반복 후 잔여 무기·탄환·컨트롤러, UI 열기/닫기, 일반 맵 복귀 시 장비·저장 상태를 검사한다. 탄환 위협 인지가 벽 뒤 탄환까지 감지하는 경우도 보완한다.
6. **최종 검증·커밋.** 수정 범위에 맞는 자동 테스트, 저장 맵 검사와 실제 컴퓨터 사용 검증을 수행한다. 현재 커밋은 중간 저장용 WIP이며 완성 판정이 아니다.

맵의 읽기 전용 검사기는 `Tools/NormalCombatTest/verify_map.py`다. 일회성 생성기는 생성 에셋과 함께 `2116397b`에 커밋한 뒤 후속 커밋에서 제거했다. 런타임은 저장된 맵을 사용한다.

# ATV 내구도·피격 연기·부분 파괴 후속 계획

상태: **2026-09-20 구현 중 / 사용자 요청으로 현재 상태 커밋**. 전체 에디터 빌드 성공 후 관련 자동 테스트 7개를 실행했고 6개가 통과했다. `DamageAndDestruction`의 막힌 출구에서 해제한 캐릭터 좌표 검사 1개가 실패하여 추가 확인이 필요하다. 파편 3개의 원본 대비 중심/크기 오차는 모두 0.000cm이며 피해 처리·연기 상태·잔해 정리의 나머지 검사는 통과했다. 오프스크린 이미지도 생성했으나 어두운 검증 장면이라 연기 가시성의 최종 시각 검수는 남아 있다. 이 커밋은 기능 검증 완료를 의미하지 않는다.

현재 선택: 최대 내구도 300, 지속 연기 65% 이하, 짙은 연기 30% 이하, 경미한 피격 방출 2초, 파괴 후 연기 20초, 분리 부품 30초. `wheel_FL`, `wheel_RR`, `handlebar` 3개를 분리하고 나머지 차체를 유지한다. UI는 새로 추가하지 않고 BP에서 내구도/상태를 읽고 조절할 수 있게 한다. 차량과 잔해 상태는 기존 차량처럼 세션 내 임시 상태로 둔다.

## 사용자 요구사항

- 차량에 내구도 항목을 둔다.
- 차량 피격 시 연기가 피어오르는 이펙트를 만든다.
- 차량 파괴 시 차체가 어느 정도 분해되어 보이게 한다.
- 지금은 계획만 남긴다.

## 구현 방향 초안

### 1. 차량 내구도와 피해 처리

- `BP_ATV_TypeA`의 부모 `ATunaSweeperATVActor`에 최대/현재 내구도와 파괴 상태를 연결한다. 표시 UI가 필요한 경우 기존 문자열 키/로컬라이징 경로를 사용한다.
- 기존 투사체의 포인트 대미지 경로에서 차량 내구도를 감소시킨다. 탑승자 피격과 차체 피격을 구분하고, 동일 명중에서 차량 피해가 중복 적용되지 않게 한다.
- 내구도 비율로 정상·손상·심각한 손상·파괴 상태를 구분한다. 최대 내구도, 피해 배율, 상태 전환 임계값은 에디터에서 조정 가능하게 설계한다.
- 파괴 처리는 한 번만 실행한다. 파괴 이후에는 주행 입력과 신규 탑승을 차단한다.

### 2. 피어오르는 연기

- Niagara로 피격 직후의 짧은 연기와 손상 상태에서 이어지는 연기를 구성하는 방안을 우선 검토한다.
- 지속 연기의 기준 위치는 엔진/차체의 지정 소켓으로 두고, 내구도 감소에 따라 양·농도·색을 조절한다. 첫 피격부터 지속시킬지, 일정 내구도 이하에서 시작할지는 실제 연출을 보며 정한다.
- 주행 중에도 방출된 연기가 차량에 붙어 끌려다니지 않도록 월드 공간에서 퍼지고 위로 올라가게 한다. 차량 속도에 따른 뒤쪽 흐름을 조절한다.
- 연속 피격 때마다 무제한으로 시스템을 생성하지 않도록 기존 효과 갱신과 방출 빈도 제한을 사용한다. 거리별 표시·최대 파티클 수·종료 처리를 함께 설정한다.

### 3. 파괴와 차체 부분 분해

- 권장 초안은 **잔해 프레임 + 미리 분리한 일부 부품**이다. 기존 스켈레탈 메시와 원본 모델에서 분리 가능한 부위를 확인한 뒤 펜더·외장 패널·짐받이·바퀴 등을 후보로 정한다.
- 초기 범위는 큰 부품 약 2~4개가 떨어져 나가는 정도로 잡고, 기본 프레임은 남겨 ATV였다는 형태를 유지한다. 정확한 부품 수와 부위는 구현 시 결정한다.
- 기존 주행 메시에서 해당 부위를 숨기거나 잔해 메시로 교체하고, 분리 부품은 원래 부위의 월드 위치·회전에서 생성한다. 차체와 부품이 중복 표시되지 않게 한다.
- 분리 부품에는 제한된 초기 속도·회전만 부여한다. 차체 내부에서 겹쳐 생성되어 크게 튀거나 플레이어를 밀지 않도록 충돌을 설정하고, 수면 상태 전환·수명·정리를 관리한다.
- 엔진 사운드와 구동을 정지하고 탑승 중인 캐릭터의 안전 하차·자세·충돌 복원을 연계한다. 안전 하차 공간이 없는 경우의 처리도 파괴 흐름과 함께 검증한다.
- Chaos Geometry Collection을 이용한 실시간 파쇄는 대안으로 남긴다. 요구한 정도의 부분 분해는 미리 분리한 부품 방식으로 먼저 구현하는 것을 권장한다.

- [x] 현재 피해 경로, 차량 메시/본/물리 애셋과 원본 모델을 확인하고 분리 부위를 선정한다.
- [ ] 내구도 감소·상태 전환·파괴 중복 방지 테스트와 차량 피해 처리를 구현한다.
- [ ] 연기 소켓과 Niagara 효과를 만들고 정지·주행·연속 피격 상태에서 조정한다.
- [ ] 잔해/분리 부품 애셋을 만들고 파괴·주행 중단·안전 하차·효과 정리를 연결한다.
- [ ] 필요하다면 내구도 표시를 기존 UI/문자열 키 흐름으로 추가한다.
- [ ] 내구도·파괴 상태·잔해 위치의 저장 여부를 기존 차량 저장 정책과 함께 결정한다. 저장 데이터를 추가할 때 `Docs/save_persistence.md`를 갱신한다.
- [ ] 아래 검증을 마친 뒤 결과를 보고한다. 일회성 애셋 생성기를 썼다면 프로젝트 규칙에 따라 애셋과 생성기를 함께 검증·커밋하고, 바로 생성기 제거·재검증·후속 커밋을 수행한다.

## 검증 기준

- 차체 명중에만 차량 내구도가 감소하며, 탑승자 피해 처리도 유지된다.
- 연속 피격·마지막 한 발·동시 피해에도 파괴 이벤트와 분리 부품이 한 번만 생성된다.
- 내구도에 맞게 연기가 바뀌고 이동 중 자연스럽게 흩어진다. 차량 제거/맵 종료 후 효과가 남지 않는다.
- 파괴 차량은 탑승·주행할 수 없고, 탑승자는 좌석이나 파괴 부품에 갇히지 않는다.
- 차체는 일부 분해되지만 과도하게 날아가지 않는다. 분리 부품도 플레이어와 차량을 비정상적으로 밀지 않는다.
- 기존 `TunaSweeper.Vehicle` 테스트의 미탑승 밀림 방지·총알 접지 제외·주행·승하차·자세 동작이 유지된다.

## 구현 시 확정할 항목

### 파괴 후 지연 폭발 연출 (2026-09-20)

- 파괴 시 기본 3초 타이머를 시작하고 `NS_Explosion_Tuna`를 잔해의 현재 위치에서 한 번 재생하도록 코드를 연결했다. 재생 시 컴포넌트를 분리해 이후 차체 이동을 따라가지 않는다.
- `DestructionExplosionDelay`를 BP 클래스 기본값 또는 레벨 인스턴스에서 조정한다. 0이면 즉시 재생하고 추가 피격은 예약을 갱신하지 않는다. 차량 제거/맵 종료 시 타이머와 이펙트를 정리한다.
- `TunaSweeper.Vehicle.DelayedExplosion`에 지연, 중복 피격, 이동 후 위치, 즉시 재생, 제거 시 취소 검사를 작성했다. 초기에는 코드와 `-NoLink` 컴파일만 확인했다. 후속 Steam Demo 패키징에서 CDO의 조기 Niagara 로드 오류를 수정한 뒤 전체 빌드·쿡·패키징과 DelayedExplosion 자동 테스트가 통과했다. 시각 검증은 미실행이다.

기본 수치와 부위는 위 선택으로 구현했다. 실제 화면·주행 검증 후 연기 크기/농도와 부품 초기 속도를 조정한다. 사용자에게 새 내구도 UI나 저장 방식 변경을 요청받으면 해당 범위를 별도로 확장한다.

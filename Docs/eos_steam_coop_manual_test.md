# EOS Steam 코옵 수동 검증

1. Win64 패키지에 EOS artifact 설정과 Steam 앱 설정을 주입하고 Steam 클라이언트 두 계정으로 실행합니다.
2. 호스트에서 온라인 코옵 위젯을 열고 방 생성 버튼을 누릅니다. 8자리 코드가 표시되고 상태가 호스트 대기로 바뀌어야 합니다.
3. 헬퍼에서 같은 위젯에 숫자 코드를 입력합니다. 8자리 미만·문자 포함 입력은 검색하지 않고 거절해야 합니다.
4. 헬퍼가 정확한 EOS 세션을 찾으면 JoinSession 뒤 호스트 리슨 서버로 이동해야 합니다.
5. 세 번째 참가 시도 또는 이미 열린 방에서는 방 가득 참으로 거절합니다.
6. 다른 프로토콜 버전의 세션, 존재하지 않는 코드, EOS 인증 실패를 각각 확인합니다. 오류 뒤 싱글플레이 버튼은 계속 사용할 수 있어야 합니다.
7. 호스트가 나가면 세션과 표시 코드를 정리하고 헬퍼가 stale 세션으로 재접속하지 않는지 확인합니다.

실제 EOS 자격증명이 없는 환경에서는 자동화된 코드/세션 메타데이터 테스트와 오프라인 fallback만 검증합니다.

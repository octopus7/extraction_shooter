# GPT-6 Astra 작업 및 검증 체크리스트

Astra(`gpt-6-astra`) 모델에 할당하여 테스트 및 수행할 작업 항목들입니다.

## 검증 항목
- [ ] 채팅에서 모델링 능력
- [ ] 컴퓨터유즈에서 페이셜 능력
- [ ] 맥에서 컴퓨터유즈 성능 윈도우와 차이
- [ ] 크론(Cron) 표현식 오프셋 지정 처리 능력 (예: `1/10 * * * *` 패턴 이해도 및 설정 검증)
- [ ] 전투 필(Game Feel) 개선 컴퓨터 유즈 (Computer Use를 활용한 인게임 전투 타격감/피드백 개선 작업)
- [ ] 데모 빌드만 퀘스트가 적용된 이유 분석 (데이터 동기화 및 퀘스트 분리 아키텍처 원인 파악)
- [ ] 세이브 슬롯 독립성 점검 (세이브 슬롯 단위가 아닌 전역(Global)으로 잘못 저장/공유되고 있는 데이터가 존재하는지 시스템 전체 코드 분석)

# Luna Mk2 사망 레그돌

플레이어 메시 `SKM_LunaMk2`가 참조하는 `SKM_LunaMk2_PhysicsAsset`을 사용한다. 사망 처리는 `ATunaSweeperTopDownCharacter::ApplyDeathRagdoll`에 있으며, 전신 물리 전환과 기존 수평/수직 충격 12000/1800을 유지한다.

## 관절 구성

2026-09-21: 기존 에셋에서 다리 twist 보조 본이 각각 골반에 직접 연결되고, 위팔이 손으로 바로 연결되어 무릎/팔꿈치 관절이 없었다. 실제 움직임을 담당하는 본에 충돌 바디를 배치하고 다음 체인으로 교체했다.

- 다리: `pelvis → thigh_l/r → calf_l/r → foot_l/r`
- 팔: `spine_04 → upperarm_l/r → lowerarm_l/r → hand_l/r`
- 몸통: `pelvis → spine_02 → spine_04 → head`
- 사이드테일: 기존 바디 4개를 유지하고 머리에서 이어지는 체인을 유지한다.

허벅지/종아리 twist 보조 본은 독립 물리 바디가 아니라 해당 본의 자식으로 따라간다. 팔다리 캡슐은 실제 바인드 포즈의 본 사이 길이와 방향으로 배치한다. 몸통·머리·머리카락의 기존 충돌 형상은 유지한다. 총 20개 바디, 19개 관절이다.

## 제한과 안정화

모든 관절의 선형 3축은 Locked다. 몸체 관절은 충격에 크게 밀리는 기본 soft cone/twist limit을 끄고 hard limit을 사용한다. 머리카락은 soft limit을 유지한다. 회전 제한은 다음과 같다. 각도는 도 단위이며 Swing1/Swing2/Twist 순서다.

| 부위 | 제한 | 기준 포즈 대비 Swing1 중심 이동 |
|---|---|---|
| 골반–아래 몸통 | 15 / 12 / 10 | 0 |
| 아래–위 몸통 | 18 / 12 / 12 | 0 |
| 목 | 25 / 20 / 30 | 0 |
| 고관절 | 65 / 35 / 20 | 15 |
| 무릎 | 65 / Locked / Locked | 60 |
| 발목 | 25 / 12 / 10 | 0 |
| 어깨 | 65 / 55 / 40 | 0 |
| 팔꿈치 | 65 / Locked / Locked | 40 |
| 손목 | 25 / 20 / 15 | 0 |
| 머리카락 뿌리/끝 | 25 / 25 / 15, 30 / 30 / 15 | 0 |

메시의 전방은 +Y다. Swing1의 Z축을 무릎은 뒤쪽, 팔꿈치는 앞쪽으로 굽혀지는 방향에 맞추고 부모 프레임에 중심 오프셋을 적용한다. 무릎은 기준 포즈 대비 약 -5~125도, 팔꿈치는 이미 굽혀진 바인드 포즈 대비 -25~105도로 움직일 수 있다. 이는 인체의 절대 굽힘 각도가 아니라 해당 리그의 바인드 포즈를 기준으로 한 범위다.

몸체 linear/angular damping은 0.35/2, 머리카락은 1/3이다. 관절은 위치 복원 스프링 없이 각속도 감쇠를 적용해 움직임을 줄인다. 바디별 질량을 명시하고 위치/속도 solver iteration을 24/4로 설정하며, UE 5.7의 `bOverrideIterationCounts`도 켜 실제 월드 물리에서 해당 값을 사용하게 한다. 인접 바디 충돌, 겹치는 골반–흉곽 충돌, 머리카락과 몸체 사이 충돌을 제외한다. 머리카락의 월드 충돌은 유지한다.

관절 projection의 선형 보정 비율은 0.8, 각도 보정 비율은 몸체 1.0/머리카락 0.2다. 반복 수만 높여서는 충돌 순간의 무릎 횡방향 오차가 남아 몸체의 각도 보정을 강화했다. 순간이동 보정 임계값은 거리 3cm/각도 15도다.

플레이어/타이틀의 머리카락 AnimGraph가 사용하는 별도 `PA_LunaMk2_SideTail`과 타이틀 치마 물리 에셋은 변경하지 않는다.

## 회귀 검사

`TunaSweeper.Character.Ragdoll.Articulation`은 양쪽 팔다리의 관절 체인, 선형 잠금, 무릎/팔꿈치의 횡방향 굽힘·비틀림 제한을 검사한다.

SkeletalMeshComponent의 초기화는 에셋의 바디별 반복 수를 컴포넌트 기본값으로 다시 덮어쓴다. 따라서 `ApplyDeathRagdoll`은 물리를 활성화한 뒤 실행 중인 바디에도 24/4 반복 수와 override를 적용한다. 살아 있는 캐릭터의 계산 비용은 늘리지 않는다.

`TunaSweeper.Character.Ragdoll.ImpactStability`는 저장된 플레이어 BP에 `TakeDamage`로 치명상을 입혀 실제 사망 경로를 실행하고 Chaos 월드에서 바닥 위로 낙하시킨다. 캐릭터 방향을 고정하고 피해 원인을 앞/뒤에 배치해 서로 반대 방향의 피격을 검사한다. 테스트에서 레벨 이동 타이머만 제거한다. 무충격 및 ±12000 수평/1800 수직 충격을 각각 8초간 시뮬레이션하고 실행 중인 바디의 반복 수, 관절 위치 오차, 관절각 제한 위반, 유한 변환, 바닥 관통 및 잔류 속도를 검사한다. 엔진의 현재 관절각 반환값은 radian이므로 degree로 변환하여 저장된 제한과 비교한다.

렌더링 가능한 실행에 `-RagdollCapture`를 추가하면 `Saved/Automation/RagdollAudit/Capture/`에 1초·3초·8초 시점의 캡처를 저장한다. 검사는 에셋을 저장하거나 재생성하지 않는다.

2026-09-21 검증: UE 5.7 Development Editor 빌드 및 두 자동화 검사 통과. 저장된 에셋을 새 렌더링 프로세스에서 다시 불러와 같은 결과를 확인했다. 세 경우의 최대 관절각 초과는 0.744/2.857/2.630도, 최대 연결 위치 오차는 0.750/3.814/1.687cm, 안정 후 오차는 0.018/0.196/0.063cm이며 마지막 1초의 선형 속도는 모두 0이었다. 1초·3초·8초 캡처를 생성하고 양방향 피격의 최종 자세를 확인했다. 이는 평면 위 지정 충격에 대한 검증이며 모든 지형/충돌 조합의 보장은 아니다.

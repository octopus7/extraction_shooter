# Unreal Editor 카메라 Pilot 사용법

## 용도

`Pilot`은 선택한 카메라의 작은 Picture-in-Picture 프리뷰를 사용하는 대신, 현재 레벨 뷰포트 전체를 해당 카메라 시점에 잠가 구도를 조정하는 기능이다.

Pilot 중의 이동과 회전은 단순한 임시 미리보기가 아니라 카메라 액터의 실제 트랜스폼에 반영된다.

## Pilot 시작

1. 레벨에 배치된 카메라 액터를 월드 아웃라이너 또는 레벨 뷰포트에서 선택한다.
2. 선택한 액터를 우클릭한다.
3. 컨텍스트 메뉴에서 `Pilot '<액터 이름>'`을 선택한다.
4. 레벨 뷰포트 전체가 선택한 카메라의 촬영 화면으로 전환되었는지 확인한다.

## 구도 조정

Pilot 상태에서는 일반 Perspective 뷰포트와 같은 방식으로 카메라를 조작한다.

- 마우스 오른쪽 버튼을 누른 상태에서 마우스를 움직여 시선을 회전한다.
- 마우스 오른쪽 버튼을 누른 상태에서 `W`, `A`, `S`, `D`로 앞·뒤·좌·우 이동한다.
- `Q`, `E`로 아래·위 이동한다.
- 마우스 휠로 뷰포트 이동 속도를 조절한다.
- 카메라 컴포넌트의 `Field Of View`는 Details 패널에서 조정한다.

뷰포트 이동 속도가 너무 빠르면 상단의 카메라 속도 값을 낮추고 미세 조정한다.

## Pilot 종료

뷰포트 좌측 상단에 표시되는 `Stop Piloting` 또는 카메라에서 분리하는 모양의 버튼을 누른다. 종료한 뒤에도 Pilot 중 조정한 카메라 액터 트랜스폼은 유지된다.

## 연출 카메라 액터 사용 시 주의점

장소 연출은 지면의 거리 판정 액터와 독립된 촬영용 `CameraActor`를 사용한다.

- 지면에 `BP_LocationBlendCamera`를 배치하고 거리 판정 중심인 `Blend Origin`을 원하는 장소에 둔다.
- 레벨에 일반 `CameraActor`를 별도로 배치한다.
- `BP_LocationBlendCamera` 인스턴스의 `Target Camera Actor`에 외부 CameraActor를 스포이드로 지정한다.
- Pilot은 외부 CameraActor에 사용하며, 지면의 판정 액터에는 사용하지 않는다.
- 거리 블렌딩은 지면 액터의 `Blend Origin` 위치를 기준으로 계산한다.
- `Blend Start Distance`는 블렌딩이 시작되는 바깥 반경이다.
- `Blend Complete Distance`는 연출 카메라로 완전히 전환되는 안쪽 반경이다.

지면의 장소 연출 액터에는 카메라 컴포넌트가 없으므로 선택 프리뷰가 표시되지 않는다. 촬영 구도는 참조된 외부 CameraActor를 Pilot해 전체 뷰포트에서 확인한다.

## 문제 해결

### Pilot 메뉴가 보이지 않는 경우

지면의 `BP_LocationBlendCamera`가 아니라 참조된 외부 CameraActor를 선택했는지 확인한다. 일반 Scene Actor나 카메라가 비활성화된 액터는 Pilot 대상으로 인식되지 않을 수 있다.

### 다른 카메라가 게임 화면을 점유하는 경우

PIE 실행 전에 Pilot 상태를 종료한다. Pilot은 에디터 뷰포트 기능이지만, 배치된 연출 카메라의 거리 조건이나 다른 카메라 전환 로직은 PIE에서 별도로 동작한다.

### 거리 판정 위치가 카메라와 함께 이동한 경우

지면의 `BP_LocationBlendCamera`와 외부 CameraActor가 서로 붙어 있거나 부모·자식으로 연결되지 않았는지 확인한다. 둘을 독립된 레벨 액터로 유지하고 `Blend Origin`만 목표 장소에 배치한다.

# 보스 전투 테스트 맵

레벨은 `/Game/Maps/BossCombatTestMap`이다. 에디터에서 이 맵을 열고 Play로 시작한다. 한 월드 안에 중앙 허브와 독립된 전투 구역 세 곳이 있으며 레벨 전환 없이 기존 워프 포인트의 F 상호작용으로 왕복한다.

- **01 CHARGE**: 바닥 돌진 예고와 몸통 공격을 학습하는 중간보스.
- **02 ROLLING ROBOTS**: 구르는 동안부터 공격할 수 있는 부하 로봇을 배출하는 중간보스.
- **03 MAIN BOSS**: 미사일 터렛·돌진·부하 로봇을 함께 사용하는 메인보스 패턴 예제.

포탈은 안전 대기 공간으로 이동한다. 도착점에서 전투 시작선까지 약 19.5m가 있으며 이동 경로를 청록색으로 표시한다. 주황색 선을 **플레이어 중심점**이 넘어 전투 구역에 들어가면 보스를 생성한다. 대기 구역에서는 보스와 공격을 생성하지 않는다. 위쪽 HUD가 SAFE STAGING / COMBAT ACTIVE / CLEARED 상태를 표시한다.

전투 구역 밖으로 후퇴하면 해당 전투의 보스·부하·터렛·미사일·예고를 정리한다. 다시 들어가면 처음부터 재시험한다. 보스 처치 뒤에도 한 번 나갔다 들어가야 새 전투를 시작한다. 다른 구역의 적이나 일반 적을 일괄 삭제하지 않는다.

기본 게임의 WASD 이동, 마우스 사격·조준, F 상호작용, R 재장전을 그대로 사용한다. 이 테스트 맵에서는 마우스 가운데 버튼으로 바닥을 클릭해 이동할 수도 있다. WASD를 누르거나 워프가 시작되면 클릭 이동을 취소한다. **Home**은 모든 테스트 전투를 초기화하고 허브에 새 캐릭터를 배치하며 체력과 소총·탄약을 보충한다. 사망 시에도 허브로 복귀한다.

테스트 게임 모드는 기존 인벤토리·장비·탄약·경험치를 메모리에 보관한 뒤 테스트 소총과 탄약을 지급한다. 맵 플레이가 끝나면 보관한 상태를 복구한다. 테스트 중 게임 저장과 전투에 따른 퀘스트·업적 진행을 차단한다. 저장 버전이나 영속 전투 상태는 추가하지 않는다.

## 재사용

`ATunaSweeperBossEncounter`는 테스트 게임 모드와 독립된 배치형 액터다. `CombatBounds`, `BossClass`, 로컬 `BossSpawnOffset`과 `BossSpawnRotation`, `EncounterId`, `DisplayName`으로 구성한다. 스폰 위치는 바닥 위의 캡슐 중심이며 구역 안에 있어야 한다. 충돌 때문에 스폰하지 못하면 밖으로 나갔다 다시 들어올 때 재시도한다.

`ResetEncounter`는 진행 중인 공격을 취소하고 해당 전투가 소유한 액터만 정리한다. 플레이어가 아직 구역 안이라면 경계를 나가기 전까지 새 전투를 시작하지 않는다. 상태는 런타임 전용이며 저장·복원하지 않는다.

## 검증

`Tools/BossCombatTest/verify_map.py`는 저장된 맵을 읽어 포탈 연결, 안전 도착 여유, 보스 클래스 분리, 전투 전 적 부재, 지형·내비게이션 배치, 테스트 게임 모드를 검사한다. 생성기는 에셋과 함께 커밋한 직후 별도 커밋으로 제거한다. 실제 포탈과 전투 시작 동작은 렌더링된 게임 창의 입력으로 별도 검증한다.

# 문서 충돌 정리

생성: 2026-05-30 16:07:53

이 문서는 오래된 기획/스토리 문서와 최근 SSOT/구현 문서가 서로 다르게 말하는 지점을 수작업 정리용으로 모은 것이다. 커밋 시각은 `git blame --date=iso-strict`의 committer date 기준이다.

## 판정 기준

- `Docs/SSOT/README.md`에 따르면 현재 기준 판단은 `Docs/SSOT` 문서를 우선한다.
- 퀘스트/아이템/대화 기준은 `Docs/SSOT/TunaSweeper_SSOT_Quest_Item_v0.6.md`와 `Docs/SSOT/TunaSweeper_Quest_Dialogue_v0.6.1.md`를 우선한다.
- `Docs/SSOT/README_SSOT_v0.6.1.md`는 v0.6.1 패키지 설명용 README이며 SSOT 색인 대상이 아니다.
- 단, `Docs/SSOT` 밖의 최근 저장/구현 문서가 실제 코드 상태를 더 직접적으로 설명하는 경우도 함께 표기했다.
- `BunkerMap`/`RaidMap` 같은 기술적 레벨 분리는 단일 대형 맵 기획과 바로 충돌한다고 보지 않았다. 다만 퀘스트 목표나 진행 구조가 달라지는 경우만 충돌로 잡았다.

| 항목 | 내용 | 권장 처리 |

## 우선 정리 순서 제안

1. 상점과 NPC 퀘스트 제공자는 2026-06-03 기준으로 정리 완료했다. 현재 기준은 벙커 자판기 거래 존재, 캔봇/시설 NPC의 제한된 퀘스트·기능 접점 존재다.
2. `검문초소`와 `창고` 용어 충돌은 최신 SSOT 기준으로 정리했다. 후반 위험 구역은 `고급보안구역`, 선택형 파밍 효율 구역은 `보급창고`, 플레이어 보관 기능은 `저장고`로 구분한다.
3. 첫 외출/벌목기/초반 우회로 흐름은 실제 메인 퀘스트 체인을 만들 때 한 번에 정리한다.
4. 플레이타임과 지역 단계 수는 스팀 문구, TODO, SSOT 표의 숫자를 같이 맞춘다.

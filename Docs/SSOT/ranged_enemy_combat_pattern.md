# 총기류 일반 적 교전 패턴

이 문서는 TunaSweeper의 총기류 일반 적 교전 패턴을 정의하는 SSOT 문서다.

총기류를 사용하는 일반 적은 이 문서의 패턴을 기본형으로 삼는다. 이후 새로운 총기 적이 추가되더라도 특별한 목적이 없다면 상태 구조는 유지하고, 거리/시간/공격 빈도/이동 성향 같은 튜닝값만 바꿔 파생한다.

## 적용 범위

- 적용 대상은 총기류 또는 투사체 사격을 주 공격으로 사용하는 일반 적이다.
- 롤링봄, 벌목기, 보스, 이벤트 전용 적은 특이 케이스로 본다.
- 롤링봄은 자체 상태 머신과 돌진/자폭 패턴을 우선한다.
- 벌목기는 근접 전용 패턴을 우선한다.
- 이 문서는 플레이어 수준의 정교한 엄폐 모드, 엄폐 사격, 피킹 전술을 요구하지 않는다.

## 설계 목표

- 총기 적은 플레이어에게 기계적으로 직선 접근하지 않는다.
- 총기 적은 사거리 밖에서 한 번에 끝까지 전진하지 않고, 짧은 전진과 정지 교전을 반복한다.
- 총기 적은 몸을 사리며 사거리를 줄이는 것처럼 보여야 한다.
- 플레이어는 적의 전진 사이사이에 대응할 수 있는 교전 창을 얻어야 한다.
- 파괴 가능한 엄폐물 뒤의 플레이어는 안전하지 않아야 한다. 적은 엄폐물을 향해 사격해서 압박한다.
- 파괴 불가능한 장애물에 발사선이 막히면 적은 그 자리에서 사격하지 않고 시야 확보 이동을 한다.

## 핵심 상태

총기류 일반 적의 기본 교전 상태는 다음을 기준으로 한다.

| 상태 | 역할 |
| --- | --- |
| `NoTarget` | 유효한 플레이어 타겟이 없거나 추적 범위 밖인 상태. |
| `EvaluateCombat` | 거리, 발사선, 엄폐물, 최근 이동 상태를 평가하는 상태. |
| `AdvanceBurst` | 제한된 거리만 전진하는 상태. 도착, 시간 초과, 발사선 변화 시 멈춘다. |
| `HoldFire` | 제자리에서 포커스와 사격을 유지하는 상태. 전진 후 반드시 일정 시간 유지한다. |
| `SeekLineOfFire` | 파괴 불가능한 장애물에 발사선이 막혔을 때 시야 확보를 위해 이동하는 상태. |
| `KeepDistance` | 플레이어가 너무 가까울 때 후퇴 또는 횡이동으로 거리권을 회복하는 상태. |

`AdvanceBurst`는 무한 추적이 아니다. 전진 시작 시 이번 전진 목표 지점과 최대 전진 시간을 정하고, 둘 중 하나가 끝나면 반드시 `HoldFire` 또는 `EvaluateCombat`으로 돌아간다.

## 거리 기준

거리 기준은 Unreal Engine 기본 단위인 cm를 사용한다. 1m는 100cm다.

| 거리권 | 기준 거리 | 기본 행동 |
| --- | --- | --- |
| 원거리 | 1800cm 이상 | 긴 전진 후 짧은 정지 교전. |
| 중거리 | 1200-1800cm | 중간 전진 후 정지 교전. |
| 선호 사격권 | 800-1200cm | 전진하지 않고 사격, 짧은 횡이동, 시야 재평가. |
| 근접 위험권 | 600cm 이하 | 후퇴 또는 횡이동으로 거리 회복. |

기본 선호 사격권은 8-12m다. 일반 총기 적은 특별한 이유 없이 이 거리권보다 더 가까이 들어가려 하지 않는다.

## 분할 전진

총기 적은 사거리 밖에서 플레이어를 향해 한 번에 끝까지 달려가지 않는다.

| 시작 거리권 | 1회 전진 거리 | 전진 후 정지 교전 시간 |
| --- | --- | --- |
| 1800cm 이상 | 400-600cm | 0.8-1.2초 |
| 1200-1800cm | 250-400cm | 1.2-1.8초 |
| 800-1200cm | 0cm | 1.4-2.2초 |

전진 거리는 현재 거리와 선호 사격권 하한을 기준으로 제한한다. 예를 들어 플레이어까지 1300cm 남았다면 400cm 전진값이 뽑혀도 800cm 안쪽으로 파고들지 않도록 보정한다.

전진에는 개체별 랜덤 오프셋을 적용한다. 여러 적이 같은 프레임에 같은 거리만큼 움직이며 멈추는 느낌을 피하기 위해 전진 거리, 전진 시간, 정지 교전 시간은 모두 작은 범위에서 흔들어야 한다.

## 정지 교전

`HoldFire` 상태에서는 적이 제자리에서 플레이어를 바라보고 사격한다.

- 사격 쿨다운은 기존 무기/AI 쿨다운을 따른다.
- 정지 교전 중에도 발사선은 주기적으로 재평가한다.
- 발사선이 열려 있으면 플레이어를 향해 사격한다.
- 발사선이 파괴 가능한 엄폐물에 막혀 있으면 그대로 사격한다.
- 발사선이 파괴 불가능한 장애물에 막혀 있으면 `SeekLineOfFire`로 전환한다.
- 플레이어가 근접 위험권까지 파고들면 `KeepDistance`로 전환한다.

정지 교전은 총기 적의 위협을 보여주는 핵심 시간이다. 너무 짧으면 다시 기계적 추적처럼 보이고, 너무 길면 적이 둔해 보인다.

## 발사선과 엄폐물

총기 적은 사격 전 `총구 또는 발사 시작점 -> 플레이어 중심` 발사선을 평가한다.

| 발사선 결과 | 행동 |
| --- | --- |
| 플레이어까지 열림 | 정상 사격. |
| 파괴 가능한 엄폐물에 막힘 | 사격 유지. 투사체가 엄폐물을 때려 압박한다. |
| 파괴 불가능한 장애물에 막힘 | 사격하지 않고 시야 확보 이동. |
| 알 수 없는 블로커 | 기본적으로 파괴 불가능한 장애물로 취급한다. |

현재 파괴 가능한 엄폐물의 대표 기준은 `ATunaSweeperSandbagCoverActor`다. 이 액터는 투사체 피해를 받아 내구도가 줄어들 수 있으므로, 적이 엄폐물을 향해 사격해도 플레이어에게 의미 있는 압박이 된다.

총기 적은 플레이어처럼 엄폐물 뒤에 붙어 피킹 사격하지 않는다. 이 문서의 엄폐 대응은 "막힌 발사선을 보고 쏠지, 움직일지 결정하는 규칙"이다.

## 시야 확보 이동

`SeekLineOfFire`는 파괴 불가능한 장애물 때문에 사격할 수 없을 때 사용한다.

- 이동 목적은 엄폐점 점유가 아니라 발사선 확보다.
- 기본은 짧은 좌/우 횡이동 또는 사선 전진이다.
- 이동 중 발사선이 열리거나 파괴 가능한 엄폐물만 남으면 `HoldFire`로 전환한다.
- 이동 시간이 너무 길어지면 `EvaluateCombat`으로 돌아가 다시 거리권을 평가한다.
- 같은 방향으로 계속 움직이는 느낌을 피하기 위해 좌/우 방향은 개체별, 전환별로 흔든다.

시야 확보 이동은 똑똑한 우회가 아니어도 된다. 플레이어에게 "벽을 쏘지 않고 자리를 바꾼다"는 느낌을 주는 것이 1차 목표다.

## 근접 위험권

플레이어가 600cm 이하로 접근하면 총기 적은 더 가까이 붙지 않는다.

기본 대응은 다음 중 하나다.

- 플레이어 반대 방향으로 짧게 후퇴한다.
- 좌/우 횡이동으로 거리를 벌린다.
- 후퇴 경로가 막히면 제자리 사격을 유지하되 다음 평가에서 다른 방향을 고른다.

근접 위험권 대응은 총기 적이 근접 적처럼 보이지 않도록 하기 위한 최소 장치다. 완벽한 카이팅을 목표로 하지 않는다.

## 파생 규칙

새 총기 적은 이 상태 구조를 유지하고 아래 튜닝값을 바꿔 성격을 만든다.

| 파생 성향 | 조정 방향 |
| --- | --- |
| 공격적 총기 적 | 전진 거리 증가, 정지 교전 시간 감소, 선호 사격권 축소. |
| 방어적 총기 적 | 전진 거리 감소, 정지 교전 시간 증가, 횡이동 비중 증가. |
| 저격형 적 | 선호 사격권 증가, 전진 빈도 감소, 시야 확보 이동 우선. |
| 산탄형 적 | 선호 사격권 감소, 근접 위험권 감소, 전진 거리 증가. |

파생 적이 새 상태를 추가해야 한다면 이 문서의 일반 패턴을 먼저 기준으로 삼고, 예외 사유를 별도 문서나 데이터에 명시한다.

## 구현 원칙

- 총기류 일반 적의 기본 구현 위치는 C++ AIController 계열이다.
- Behavior Tree는 현재 프로젝트 기준에서 기본 사용 대상이 아니다.
- 거리, 시간, 전진 거리, 선호 거리권은 하드코딩 상수로 고정하지 않고 데이터화할 수 있어야 한다.
- 롤링봄과 벌목기 판정은 이 일반 패턴에 섞지 않는다.
- 기존 원거리 적의 `ApproachStartRange`와 `ApproachStopRange`만으로는 이 문서의 패턴을 만족하지 못한다.
- 구현 후에는 "1800cm 이상에서 적이 800-1000cm까지 한 번에 직선 접근하지 않는지"를 확인해야 한다.

## 수용 기준

- 총기 적은 10m 바깥에서 플레이어에게 한 번에 달라붙지 않는다.
- 총기 적은 전진 후 반드시 일정 시간 정지 교전을 한다.
- 거리가 멀수록 1회 전진 거리가 길고, 선호 사격권에 가까울수록 짧거나 0에 가깝다.
- 파괴 가능한 엄폐물 뒤의 플레이어를 향해서는 사격을 유지한다.
- 파괴 불가능한 장애물 뒤의 플레이어를 향해서는 벽을 계속 쏘지 않고 시야 확보 이동을 한다.
- 플레이어가 너무 가까이 붙으면 총기 적은 후퇴 또는 횡이동을 시도한다.

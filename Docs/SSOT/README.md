# SSOT

이 경로는 TunaSweeper 프로젝트의 진행 상태, 설계 기준, 구현 기준이 서로 어긋나지 않도록 관리하기 위한 Single Source of Truth(SSOT) 문서를 모아두기 위해 만들었다.

여기에 들어가는 문서는 현재 기준으로 무엇이 맞는지 판단할 때 우선 참조하는 원본 역할을 한다.

특별한 언급이 없으면 진행/설계 기준 변경은 이 경로의 SSOT 문서만 먼저 수정한다. 기존 스토리, 기획, 구현 보조 문서는 별도 동기화 요청이 있을 때 SSOT 기준으로 맞춘다.

## 현재 우선 기준

- `TunaSweeper_SSOT_Quest_Item_v0.6.md`: 맵 진행, 메인/선택 퀘스트, 아이템, 이미지 생성용 외양 묘사의 우선 기준.
- `TunaSweeper_Quest_Dialogue_v0.6.1.md`: 퀘스트별 시작/요구 안내/부족/완료 대화의 우선 기준. 퀘스트 구조는 `TunaSweeper_SSOT_Quest_Item_v0.6.md`를 따른다.

## 보조 문서

- `README_SSOT_v0.6.1.md`: v0.6.1 패키지 설명용 README다. SSOT 색인 대상이나 별도 설계 기준 문서로 취급하지 않는다.

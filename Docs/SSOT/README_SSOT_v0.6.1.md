# Tuna Sweeper SSOT Package v0.6.1

이 zip은 현재까지 정리된 퀘스트/아이템 SSOT와 퀘스트 대화집을 포함한다.

## 포함 파일

- `TunaSweeper_SSOT_Quest_Item_v0.6.md`  
  퀘스트 구조, 선행조건, Mermaid 그래프, 아이템 정보, 이미지 생성용 외양 묘사.

- `TunaSweeper_Quest_Dialogue_v0.6.1.md`  
  메인/선택/하우징/부수/엔딩 후 퀘스트별 시작/요구 안내/부족/완료 대화.

## 반영된 핵심 규칙

- 포탈은 메인 퀘스트에서 언급하지 않는다.
- 콘크리트 더미는 “막힌 길을 부술 수 있다” 정도로만 암시한다.
- 화장실 수리는 실제 기능/퀘스트가 아니라 M03, M04, S20의 개그 대화로만 사용한다.
- 수납량은 장착 가방으로 늘린다. 기존 영구 수납 확장 기획과 S01~S03은 폐기했다.
- `고급보안구역` 명칭을 사용한다.

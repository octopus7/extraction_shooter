# 적 발화

## 기본 동작

- `ATunaSweeperEnemyCharacter`와 그 파생 적(일반 적, 보스/중간보스, 사족 적, 롤링 봄버, 구르는 부하 로봇)에 적용한다. 플레이어·아군·중립 대상과 체력 없는 환경 오브젝트에는 적용하지 않는다.
- 기본 소이탄은 명중 피해가 실제 적용된 살아 있는 적에게 발화를 건다. 기본 지속시간 5초, 틱 간격 1초, 틱당 피해 2이며 최초 피해는 발화 1초 뒤다. 총 5틱 이후 종료한다.
- 동일 적에게 발화는 하나만 유지한다. 재명중은 남은 시간을 새 지속시간 이상으로 갱신하고 다음 피해 시점은 미루지 않는다. 더 약한 발화는 기존 틱 피해를 낮추지 않으며 강한 발화가 피해와 처치 주체를 갱신한다.
- 프레임 지연 시 실제 지속시간 안에 발생한 틱만 보충한다. 사망·제거·아군 전환 시 정리하며 무한 지속은 없다.
- 기존 `/Game/Effects/NS_ExplosiveBarrel_Burning`을 몸에 붙여 사용한다. 불꽃은 적과 함께 이동하면서 월드 위쪽으로 피어오르고, 발화 종료/사망 시 즉시 제거한다. 컴포넌트 기본값에서 이펙트·위치·크기를 조정할 수 있다.
- 지속 피해도 일반 적 피해 경로를 사용해 적 반응·피해 숫자·처치 경험치·퀘스트/업적·전리품 처리가 이어진다. 최초 투사체가 없어져도 발사자와 컨트롤러를 보존한다.

## 탄약과 연구

- 소총 소이탄 아이템 ID `2023`: 소총 탄약과 호환되며 상점에서 구매할 수 있다. 기본 2 피해 × 5틱. 기존 탄약은 발화를 일으키지 않는다.
- 아이템 데이터의 `burn_damage_per_tick`이 0보다 큰 무기 또는 탄약만 발화를 활성화한다. `burn_tick_count` 기본값은 5다. 둘 다 설정되어 있으면 기본 피해와 틱 수를 각각 큰 값으로 선택한다.
- `weapon_burn_1/2`, `ammo_burn_1/2` 연구는 각각 지속시간 +1초, 기본 틱 피해 +25%를 준다. 완료 버튼을 눌러 적용한 연구만 반영한다.
- 네 연구를 모두 적용한 소총 소이탄은 9초 동안 9틱, 틱당 4 피해다. 배율 보너스는 가산한다.
- 연구 효과 `weapon_burn_ticks`/`ammo_burn_ticks`는 정수 틱 수, `weapon_burn_damage`/`ammo_burn_damage`는 10000분율 보너스(`2500 = +25%`)다. `target_type_tag`로 총종 또는 탄종을 지정하며 비어 있으면 해당 종류 전체에 적용한다.
- 연구만으로 일반 탄약에 발화를 부여하지 않는다. 발사 순간 장전 탄약·무기·적용 연구에서 값을 확정해 각 투사체에 복사한다.

## 구현 진입점과 저장

- `UTunaSweeperBurnComponent::TryApplyBurn`은 `FTunaSweeperBurnSpec`과 피해 주체를 받는 권한 측 진입점이다. 적의 `GetBurnComponent()`로 접근할 수 있다.
- `TunaSweeperBurn::ResolveWeaponBurnSpec`이 무기/탄약 데이터와 연구 보정을 결합한다. 플레이어 사격 → 무기 → 투사체 → 적 발화 순서로 전달한다.
- 발화는 전투 중 런타임 상태이며 맵 이동/로드 시 복원하지 않는다. 연구는 기존 `AppliedResearchNodeIds`, 소이탄과 장전 상태는 기존 아이템 저장 구조를 사용한다. 추가 저장 필드나 세이브 버전 변경은 없다.
